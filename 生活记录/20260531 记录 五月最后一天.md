# 20260531 记录 五月最后一天

最近的生活又开始一潭死水了，基本没有任何进步，每天都是在重复，等待着什么到来。

每天只是重复了几件事情，依靠小红书或者短视频消磨时间，最后却又什么都没有剩下。

又开始了一段：遗忘 -> 很久不用 -> 突然想起来 -> 要是一直如此就好了，要是早一点知道就好了 -> 依然重复。

还是要早一点锻炼一下面试能力，准备好退路，最好是外企，这样就能有自己的一些生活了。其次是公司高福利好的纯互联网公司，学习锻炼一下自己的能力，顾不上生活至少能多赚点钱。最后是体制内，做好可持续发展的打算。
