# 八股笔记（1）

## 线程和进程的区别？ 

- 进程是正在运行的程序的实例，进程中包含了线程，每个线程执行不同的任务。
- 不同的进程使用不同的内存空间，而同一进程下的所有线程可以共享内存空间。
- 线程更轻量，线程上下文切换成本一般要比进程上下文切换低（上下文切换指的是从一个线程切换到另外一个线程）。

## 协程的区别

- 协程是一种更轻量级的线程，可以在单个线程中以非阻塞的方式执行多个任务。
- 与线程和进程不同，协程的切换不需要操作系统内核的参与，而是由程序自身来管理，因此切换成本更低。
- 协程在同一线程内共享相同的上下文和内存空间，这使得它们之间的**数据共享**和**通信**更加简单。
- 协程支持挂起和恢复的功能，这使得协程可以在等待I/O操作或其他耗时任务时释放线程资源，使其他协程得以执行，从而提高并发性能。
- 协程可以用同步的编程风格实现异步的执行效果，代码结构更加清晰和易于维护。

## 并发和并发的区别？

**预置知识**：

单核CPU下线程实际还是串行执行的

操作系统中有一个组件叫做任务调度器，将cpu的时间片（windows下时间片最小约为15ms）分给不同的程序使用，只是由于cpu在线程间（时间片很短）的切换非常快，人类感觉是同时运行的

将线程轮流使用CPU的做法称之为并发（concurrent）

**多核CPU**：每个核（core）都可以调度运行线程，这时候线程可以是并行的

- **并发（concurrent）**是同一时间应对（dealing with）多件事情的能力， 多个线程轮流使用一个或多个CPU。
- **并行（parallel）**是同一时间动手做（doing）多件事情的能力， 4核CPU同时执行4个线程。

## `Static`关键字在`C/C++` 和 `Java` 中的作用

`static` 关键字在 C/C++ 和 Java 中有不同的作用，具体如下：

### 1. 在 C/C++ 中：
- **静态变量（局部变量）**：如果在函数内部使用 `static`，该变量将被分配在静态内存区，整个程序生命周期中只初始化一次，且保持其值不变。即使函数多次被调用，`static` 变量的值也会保留。
    
    ```c
    void func() {
        static int count = 0;
        count++;
        printf("%d\n", count);
    }
    // 每次调用 func() 时，count 的值都会递增。
    ```
- **静态全局变量**：如果在函数外使用 `static`，该变量仅在当前文件可见，其他文件无法引用它。它的作用类似于封装，只限于当前编译单元使用。
    
    ```c
    static int globalVar = 100;
    ```
- **静态函数**：如果一个函数被声明为 `static`，它只在定义它的文件内部可见，其他文件不能调用这个函数。
    ```c
    static void myFunction() {
        // 仅在当前文件中可调用
    }
    ```

### 2. 在 Java 中：
- **静态变量（类变量）**：`static` 修饰的变量属于类本身，而不是类的某个实例。所有实例共享这个变量的值，改变一个对象的静态变量会影响所有其他对象。
    
    ```java
    class MyClass {
        static int staticVar = 100;
    }
    ```
- **静态方法**：`static` 修饰的方法属于类本身，可以通过类名直接调用，而不需要创建对象实例。静态方法中不能访问非静态成员（即实例变量和实例方法），因为它们与具体的对象绑定。
    ```java
    class MyClass {
        static void staticMethod() {
            System.out.println("This is a static method.");
        }
    }
    ```
- **静态代码块**：用于在类加载时运行一次。通常用于初始化静态变量。
    ```java
    class MyClass {
        static {
            System.out.println("Static block executed.");
        }
    }
    ```

### 总结：
- 在 **C/C++** 中，`static` 主要用于控制变量和函数的作用域（文件作用域和局部静态变量的生命周期）。
- 在 **Java** 中，`static` 主要用于定义类成员（变量和方法），这些成员属于类本身，而不是类的实例。
