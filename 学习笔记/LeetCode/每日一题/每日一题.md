## 0109 多路归并 — 合并 K 个升序链表

**题目**: [23. 合并 K 个升序链表](https://leetcode.cn/problems/merge-k-sorted-lists/)

**分类**: 链表 / 多路归并 / 优先队列

**思路**: 多路归并的核心是将 K 个有序序列的头部放入小根堆，每次弹出最小值接至结果链表，再将弹出节点的 next 入堆。利用优先队列（`heapq` 或 `priority_queue`）将比较次数从 O(NK) 降为 O(N log K)。

**代码 (Python)**:
```python
import heapq

class Solution:
    def mergeKLists(self, lists: List[Optional[ListNode]]) -> Optional[ListNode]:
        dummy = ListNode()
        cur = dummy
        heap = []
        for i, node in enumerate(lists):
            if node:
                heapq.heappush(heap, (node.val, i, node))
        while heap:
            val, i, node = heapq.heappop(heap)
            cur.next = node
            cur = cur.next
            if node.next:
                heapq.heappush(heap, (node.next.val, i, node.next))
        return dummy.next
```

**复杂度**: 时间 O(N log K) | 空间 O(K)

## 0110 前缀和 — 和为 K 的子数组

**题目**: [560. 和为 K 的子数组](https://leetcode.cn/problems/subarray-sum-equals-k/)

**分类**: 数组 / 前缀和 / 哈希表

**思路**: 枚举子数组起点 O(N²) 会超时。利用前缀和 + 哈希表：`pre[i] - pre[j-1] == k` 等价于 `pre[j-1] == pre[i] - k`。遍历时维护前缀和及其出现次数，累加满足条件的次数即可。

**代码 (Python)**:
```python
class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        cnt = {0: 1}
        ans = s = 0
        for x in nums:
            s += x
            ans += cnt.get(s - k, 0)
            cnt[s] = cnt.get(s, 0) + 1
        return ans
```

**复杂度**: 时间 O(N) | 空间 O(N)

## 0111 滑动窗口 — 无重复字符的最长子串

**题目**: [3. 无重复字符的最长子串](https://leetcode.cn/problems/longest-substring-without-repeating-characters/)

**分类**: 字符串 / 滑动窗口 / 哈希表

**思路**: 用双指针维护一个不含重复字符的窗口。右指针不断右移，遇到重复字符时左指针跳至上一次该字符出现位置的右侧。用数组或哈希表记录每个字符最近出现的下标。

**代码 (Python)**:
```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        idx = {}
        ans = l = 0
        for r, c in enumerate(s):
            if c in idx and idx[c] >= l:
                l = idx[c] + 1
            else:
                ans = max(ans, r - l + 1)
            idx[c] = r
        return ans
```

**复杂度**: 时间 O(N) | 空间 O(∣Σ∣)

## 0112 二分答案 — 在 D 天内送达包裹

**题目**: [1011. 在 D 天内送达包裹的能力](https://leetcode.cn/problems/capacity-to-ship-packages-within-d-days/)

**分类**: 二分查找 / 贪心

**思路**: 运载能力下界为 max(weights)，上界为 sum(weights)。对每个 mid 模拟装载过程，若所需天数 ≤ D 则右移左边界，否则左移右边界。经典的「最小值最大化」二分答案模型。

**代码 (C++)**:
```cpp
class Solution {
public:
    int shipWithinDays(vector<int>& weights, int days) {
        auto check = [&](int cap) {
            int cur = 0, d = 1;
            for (int w : weights) {
                if (cur + w > cap) cur = 0, d++;
                cur += w;
            }
            return d <= days;
        };
        int l = *max_element(weights.begin(), weights.end());
        int r = accumulate(weights.begin(), weights.end(), 0);
        while (l < r) {
            int m = l + (r - l) / 2;
            if (check(m)) r = m;
            else l = m + 1;
        }
        return l;
    }
};
```

**复杂度**: 时间 O(N log S) | 空间 O(1)

## 0113 拓扑排序 — 课程表

**题目**: [207. 课程表](https://leetcode.cn/problems/course-schedule/)

**分类**: 图 / 拓扑排序 / BFS

**思路**: 将课程依赖关系建模为有向图，统计每个节点的入度。将入度为 0 的节点入队，逐层移除并更新邻居入度。若最终所有节点均被遍历则无环，否则有环。Kahn 算法的典型应用。

**代码 (Python)**:
```python
class Solution:
    def canFinish(self, numCourses: int, prerequisites: List[List[int]]) -> bool:
        g = [[] for _ in range(numCourses)]
        indeg = [0] * numCourses
        for a, b in prerequisites:
            g[b].append(a)
            indeg[a] += 1
        q = [i for i in range(numCourses) if indeg[i] == 0]
        for i in q:
            for j in g[i]:
                indeg[j] -= 1
                if indeg[j] == 0:
                    q.append(j)
        return len(q) == numCourses
```

**复杂度**: 时间 O(V + E) | 空间 O(V + E)

## 0114 动态规划 — 最长递增子序列

**题目**: [300. 最长递增子序列](https://leetcode.cn/problems/longest-increasing-subsequence/)

**分类**: 动态规划 / 二分查找 / 贪心

**思路**: 常规 DP 为 O(N²)：`dp[i] = max(dp[j] + 1)`。优化版本维护 tails 数组，`tails[i]` 表示长度为 i+1 的递增子序列的最小末尾元素。遍历时二分查找第一个 ≥ num 的位置并替换，`tails` 的长度即为 LIS 长度。

**代码 (Python)**:
```python
class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        tails = []
        for x in nums:
            i = bisect_left(tails, x)
            if i == len(tails):
                tails.append(x)
            else:
                tails[i] = x
        return len(tails)
```

**复杂度**: 时间 O(N log N) | 空间 O(N)

## 0115 回溯 — 全排列

**题目**: [46. 全排列](https://leetcode.cn/problems/permutations/)

**分类**: 回溯 / DFS / 剪枝

**思路**: 标准回溯模板。用 `path` 记录当前路径，`used` 数组标记元素是否已被选择。每次从剩余可选元素中选一个加入 path，递归后撤销选择（回溯）。不含重复元素的排列无需排序剪枝。

**代码 (Python)**:
```python
class Solution:
    def permute(self, nums: List[int]) -> List[List[int]]:
        ans, n = [], len(nums)
        used = [False] * n
        def dfs(path):
            if len(path) == n:
                ans.append(path[:])
                return
            for i in range(n):
                if not used[i]:
                    used[i] = True
                    path.append(nums[i])
                    dfs(path)
                    path.pop()
                    used[i] = False
        dfs([])
        return ans
```

**复杂度**: 时间 O(N · N!) | 空间 O(N)

## 0116 并查集 — 被围绕的区域

**题目**: [130. 被围绕的区域](https://leetcode.cn/problems/surrounded-regions/)

**分类**: 并查集 / DFS / 连通分量

**思路**: 将边界上的 'O' 与虚拟节点连通，内部的 'O' 与相邻的 'O' 连通。最后遍历矩阵，未与虚拟节点连通的 'O' 即为被包围的，翻转为 'X'。并查集适用于连通性判断。

**代码 (C++)**:
```cpp
class UnionFind {
    vector<int> p;
public:
    UnionFind(int n) : p(n) { iota(p.begin(), p.end(), 0); }
    void unite(int a, int b) { p[find(a)] = find(b); }
    int find(int x) { return p[x] == x ? x : p[x] = find(p[x]); }
};

class Solution {
public:
    void solve(vector<vector<char>>& board) {
        if (board.empty()) return;
        int m = board.size(), n = board[0].size();
        UnionFind uf(m * n + 1);
        int dummy = m * n;
        int dirs[5] = {-1, 0, 1, 0, -1};
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (board[i][j] != 'O') continue;
                if (i == 0 || i == m-1 || j == 0 || j == n-1)
                    uf.unite(i * n + j, dummy);
                for (int d = 0; d < 4; d++) {
                    int x = i + dirs[d], y = j + dirs[d+1];
                    if (x >= 0 && x < m && y >= 0 && y < n && board[x][y] == 'O')
                        uf.unite(i * n + j, x * n + y);
                }
            }
        }
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                if (board[i][j] == 'O' && uf.find(i * n + j) != uf.find(dummy))
                    board[i][j] = 'X';
    }
};
```

**复杂度**: 时间 O(M × N × α) | 空间 O(M × N)

## 0117 单调栈 — 每日温度

**题目**: [739. 每日温度](https://leetcode.cn/problems/daily-temperatures/)

**分类**: 栈 / 单调栈

**思路**: 维护一个递减（从栈底到栈顶）的单调栈，栈中存下标。遍历温度数组时，若当前温度高于栈顶下标对应的温度，则栈顶下标的结果已经确定（当前下标 - 栈顶下标），弹出栈顶。继续比较直至栈空或栈顶温度 ≥ 当前温度，再将当前下标入栈。

**代码 (Python)**:
```python
class Solution:
    def dailyTemperatures(self, temperatures: List[int]) -> List[int]:
        n = len(temperatures)
        ans = [0] * n
        stk = []
        for i in range(n):
            while stk and temperatures[i] > temperatures[stk[-1]]:
                j = stk.pop()
                ans[j] = i - j
            stk.append(i)
        return ans
```

**复杂度**: 时间 O(N) | 空间 O(N)

## 0118 树形 DP — 打家劫舍 III

**题目**: [337. 打家劫舍 III](https://leetcode.cn/problems/house-robber-iii/)

**分类**: 树 / 树形 DP / DFS

**思路**: 每个节点有两种状态：偷或不偷。若偷当前节点，则不能偷左右子节点；若不偷，则可偷或不偷子节点（取大者）。后序遍历返回 `(f, g)` 分别表示偷/不偷当前节点时的最大金额。

**代码 (Python)**:
```python
class Solution:
    def rob(self, root: Optional[TreeNode]) -> int:
        def dfs(node):
            if not node:
                return (0, 0)
            l_rob, l_not = dfs(node.left)
            r_rob, r_not = dfs(node.right)
            rob = node.val + l_not + r_not
            not_rob = max(l_rob, l_not) + max(r_rob, r_not)
            return (rob, not_rob)
        return max(dfs(root))
```

**复杂度**: 时间 O(N) | 空间 O(H)

## 0119 字典树 — 实现 Trie

**题目**: [208. 实现 Trie (前缀树)](https://leetcode.cn/problems/implement-trie-prefix-tree/)

**分类**: 设计 / 字典树 / 字符串

**思路**: 每个节点包含一个长度为 26 的子节点指针数组和一个布尔标志位 `is_end`。`insert` 按字符逐层创建节点，`search` 逐层查找并在结尾检查标志位，`startsWith` 仅需确认路径存在。

**代码 (C++)**:
```cpp
class Trie {
    struct Node {
        Node* ch[26] = {};
        bool end = false;
    };
    Node* root;
public:
    Trie() { root = new Node(); }
    void insert(string word) {
        Node* p = root;
        for (char c : word) {
            int i = c - 'a';
            if (!p->ch[i]) p->ch[i] = new Node();
            p = p->ch[i];
        }
        p->end = true;
    }
    bool search(string word) {
        Node* p = root;
        for (char c : word) {
            int i = c - 'a';
            if (!p->ch[i]) return false;
            p = p->ch[i];
        }
        return p->end;
    }
    bool startsWith(string prefix) {
        Node* p = root;
        for (char c : prefix) {
            int i = c - 'a';
            if (!p->ch[i]) return false;
            p = p->ch[i];
        }
        return true;
    }
};
```

**复杂度**: 时间 O(∣S∣) per op | 空间 O(N × ∣Σ∣)

## 0120 最短路 — 网络延迟时间

**题目**: [743. 网络延迟时间](https://leetcode.cn/problems/network-delay-time/)

**分类**: 图 / Dijkstra / 最短路

**思路**: 单源最短路，边权均为正，使用 Dijkstra。每次从候选集中选出距离最小的节点（小根堆优化），松弛其邻居。最终所有节点中距离的最大值即为信号到达所有节点的最短时间。若有节点不可达返回 -1。

**代码 (Python)**:
```python
class Solution:
    def networkDelayTime(self, times: List[List[int]], n: int, k: int) -> int:
        g = [[] for _ in range(n)]
        for u, v, w in times:
            g[u-1].append((v-1, w))
        dist = [inf] * n
        dist[k-1] = 0
        pq = [(0, k-1)]
        while pq:
            d, u = heapq.heappop(pq)
            if d > dist[u]:
                continue
            for v, w in g[u]:
                nd = d + w
                if nd < dist[v]:
                    dist[v] = nd
                    heapq.heappush(pq, (nd, v))
        ans = max(dist)
        return ans if ans != inf else -1
```

**复杂度**: 时间 O((V + E) log V) | 空间 O(V + E)

## 0121 区间 DP — 最长回文子串

**题目**: [5. 最长回文子串](https://leetcode.cn/problems/longest-palindromic-substring/)

**分类**: 字符串 / 动态规划 / 中心扩展

**思路**: 区间 DP 定义 `dp[i][j]` 表示 s[i..j] 是否为回文串，状态转移 `dp[i][j] = (s[i]==s[j]) and (j-i<2 or dp[i+1][j-1])`。也可以用中心扩展法：从每个字符或两个字符之间的空隙向两边扩展，记录最长回文。

**代码 (Python — 中心扩展)**:
```python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        def expand(l, r):
            while l >= 0 and r < len(s) and s[l] == s[r]:
                l -= 1
                r += 1
            return s[l+1:r]
        ans = ""
        for i in range(len(s)):
            s1 = expand(i, i)
            s2 = expand(i, i+1)
            ans = max(ans, s1, s2, key=len)
        return ans
```

**复杂度**: 时间 O(N²) | 空间 O(1)

## 0122 BFS — 二叉树的层序遍历

**题目**: [102. 二叉树的层序遍历](https://leetcode.cn/problems/binary-tree-level-order-traversal/)

**分类**: 树 / BFS / 队列

**思路**: 利用队列逐层遍历。每次处理当前队列中的所有节点（即当前层），将其子节点加入队列作为下一层。记录每层的节点值列表，最终返回二维数组。

**代码 (C++)**:
```cpp
class Solution {
public:
    vector<vector<int>> levelOrder(TreeNode* root) {
        if (!root) return {};
        vector<vector<int>> ans;
        queue<TreeNode*> q;
        q.push(root);
        while (!q.empty()) {
            int sz = q.size();
            vector<int> level;
            while (sz--) {
                auto node = q.front(); q.pop();
                level.push_back(node->val);
                if (node->left) q.push(node->left);
                if (node->right) q.push(node->right);
            }
            ans.push_back(level);
        }
        return ans;
    }
};
```

**复杂度**: 时间 O(N) | 空间 O(N)

## 0123 差分数组 — 航班预订统计

**题目**: [1109. 航班预订统计](https://leetcode.cn/problems/corporate-flight-bookings/)

**分类**: 数组 / 差分 / 前缀和

**思路**: 区间频繁增减操作优先考虑差分数组。对 `[l, r]` 区间增加 val，在差分数组 `diff[l] += val`，`diff[r+1] -= val`。最后对差分数组求一次前缀和即得到每个位置的最终值。

**代码 (Python)**:
```python
class Solution:
    def corpFlightBookings(self, bookings: List[List[int]], n: int) -> List[int]:
        diff = [0] * (n + 1)
        for l, r, seats in bookings:
            diff[l-1] += seats
            diff[r] -= seats
        for i in range(1, n):
            diff[i] += diff[i-1]
        return diff[:n]
```

**复杂度**: 时间 O(N + M) | 空间 O(N)

## 0125 快速选择 — 数组中的第 K 个最大元素

**题目**: [215. 数组中的第 K 个最大元素](https://leetcode.cn/problems/kth-largest-element-in-an-array/)

**分类**: 分治 / 快速选择 / 堆

**思路**: 快速选择是快速排序的变体。每次 partition 后将基准归位，若基准位置正好是 n-k 则直接返回；若小于则在右侧继续，否则在左侧。平均 O(N)，最坏 O(N²)。

**代码 (Python)**:
```python
class Solution:
    def findKthLargest(self, nums: List[int], k: int) -> int:
        def partition(l, r):
            pivot = nums[random.randint(l, r)]
            i, j = l, r
            while i <= j:
                while nums[i] < pivot: i += 1
                while nums[j] > pivot: j -= 1
                if i <= j:
                    nums[i], nums[j] = nums[j], nums[i]
                    i += 1
                    j -= 1
            return i
        n = len(nums)
        l, r = 0, n - 1
        target = n - k
        while True:
            idx = partition(l, r)
            if idx == target:
                return nums[idx]
            elif idx < target:
                l = idx + 1
            else:
                r = idx - 1
```

**复杂度**: 平均时间 O(N) | 空间 O(log N)

## 0126 状态压缩 DP — 最短超级串

**题目**: [943. 最短超级串](https://leetcode.cn/problems/find-the-shortest-superstring/)

**分类**: 位运算 / 状态压缩 DP / 字符串

**思路**: 先预处理 `overlap[i][j]` 表示将 words[j] 接在 words[i] 后面时重叠部分的长度。定义 `dp[mask][i]` 表示已访问集合为 mask、最后一个单词为 i 时的最短长度。转移时枚举下一个单词 j 更新 dp。最后回溯构造字符串。

**代码 (C++)**:
```cpp
class Solution {
public:
    string shortestSuperstring(vector<string>& words) {
        int n = words.size();
        vector<vector<int>> ov(n, vector<int>(n));
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                for (int k = min(words[i].size(), words[j].size()); k > 0; k--)
                    if (words[i].substr(words[i].size() - k) == words[j].substr(0, k)) {
                        ov[i][j] = k; break;
                    }
        vector<vector<int>> dp(1<<n, vector<int>(n, 1e9));
        vector<vector<int>> parent(1<<n, vector<int>(n, -1));
        for (int i = 0; i < n; i++) dp[1<<i][i] = words[i].size();
        for (int mask = 1; mask < (1<<n); mask++) {
            for (int i = 0; i < n; i++) {
                if (!(mask >> i & 1)) continue;
                for (int j = 0; j < n; j++) {
                    if (mask >> j & 1) continue;
                    int nmask = mask | (1 << j);
                    int val = dp[mask][i] + words[j].size() - ov[i][j];
                    if (val < dp[nmask][j]) {
                        dp[nmask][j] = val;
                        parent[nmask][j] = i;
                    }
                }
            }
        }
        int mask = (1 << n) - 1, last = 0;
        for (int i = 1; i < n; i++)
            if (dp[mask][i] < dp[mask][last]) last = i;
        string ans;
        while (mask) {
            int prev = parent[mask][last];
            if (prev == -1) ans = words[last] + ans;
            else ans = words[last].substr(ov[prev][last]) + ans;
            mask ^= 1 << last;
            last = prev;
        }
        return ans;
    }
};
```

**复杂度**: 时间 O(N² · 2^N) | 空间 O(N · 2^N)

## 0127 树状数组 — 逆序对

**题目**: [LCR 170. 交易逆序对的总数](https://leetcode.cn/problems/shu-zu-zhong-de-ni-xu-dui-lcof/)

**分类**: 树状数组 / 离散化 / 分治

**思路**: 将原数组离散化（或利用值域），从后往前遍历，每次查询比当前元素小的个数（即前缀和），累加到答案，再将当前元素插入树状数组。也可以使用归并排序的分治思想。

**代码 (Python — 树状数组)**:
```python
class BIT:
    def __init__(self, n):
        self.n = n
        self.t = [0] * (n + 1)
    def add(self, i, v):
        while i <= self.n:
            self.t[i] += v
            i += i & -i
    def sum(self, i):
        s = 0
        while i > 0:
            s += self.t[i]
            i -= i & -i
        return s

class Solution:
    def reversePairs(self, record: List[int]) -> int:
        arr = sorted(set(record))
        m = {v: i+1 for i, v in enumerate(arr)}
        bit = BIT(len(arr))
        ans = 0
        for x in reversed(record):
            ans += bit.sum(m[x] - 1)
            bit.add(m[x], 1)
        return ans
```

**复杂度**: 时间 O(N log N) | 空间 O(N)

## 0128 记忆化搜索 — 矩阵中最长递增路径

**题目**: [329. 矩阵中的最长递增路径](https://leetcode.cn/problems/longest-increasing-path-in-a-matrix/)

**分类**: DFS / 记忆化搜索 / 拓扑排序

**思路**: 对每个单元格进行 DFS 并缓存计算结果（记忆化），避免重复计算。从某个单元格出发的最长递增路径 = 1 + max(四个方向中比当前值大的单元格的最长路径)。也可以转化为 DAG 拓扑排序求解。

**代码 (Python)**:
```python
class Solution:
    def longestIncreasingPath(self, matrix: List[List[int]]) -> int:
        m, n = len(matrix), len(matrix[0])
        memo = [[0] * n for _ in range(m)]
        dirs = [(0,1),(0,-1),(1,0),(-1,0)]
        def dfs(i, j):
            if memo[i][j]:
                return memo[i][j]
            best = 1
            for dx, dy in dirs:
                x, y = i + dx, j + dy
                if 0 <= x < m and 0 <= y < n and matrix[x][y] > matrix[i][j]:
                    best = max(best, 1 + dfs(x, y))
            memo[i][j] = best
            return best
        return max(dfs(i, j) for i in range(m) for j in range(n))
```

**复杂度**: 时间 O(M × N) | 空间 O(M × N)

## 0129 双指针 — 三数之和

**题目**: [15. 三数之和](https://leetcode.cn/problems/3sum/)

**分类**: 双指针 / 排序 / 去重

**思路**: 先排序，固定一个数 `nums[i]`，用双指针在剩余区间寻找两数之和等于 `-nums[i]`。去重技巧：i 跳过相同值；找到答案后左右指针跳过相同值。注意剪枝：若 `nums[i] > 0` 可直接结束。

**代码 (Python)**:
```python
class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
        nums.sort()
        ans, n = [], len(nums)
        for i in range(n - 2):
            if i > 0 and nums[i] == nums[i-1]:
                continue
            if nums[i] > 0:
                break
            l, r = i + 1, n - 1
            while l < r:
                s = nums[i] + nums[l] + nums[r]
                if s == 0:
                    ans.append([nums[i], nums[l], nums[r]])
                    while l < r and nums[l] == nums[l+1]: l += 1
                    while l < r and nums[r] == nums[r-1]: r -= 1
                    l += 1
                    r -= 1
                elif s < 0:
                    l += 1
                else:
                    r -= 1
        return ans
```

**复杂度**: 时间 O(N²) | 空间 O(log N) ~ O(N)

## 0130 贪心 — 跳跃游戏 II

**题目**: [45. 跳跃游戏 II](https://leetcode.cn/problems/jump-game-ii/)

**分类**: 贪心 / BFS

**思路**: 维护当前步数下能到达的最远边界 `end`，以及下一步能到达的最远位置 `farthest`。遍历数组，每走到 `end` 时步数加一，更新 `end = farthest`。核心思想是在每一步的可达范围内选择能跳最远的点。

**代码 (C++)**:
```cpp
class Solution {
public:
    int jump(vector<int>& nums) {
        int ans = 0, end = 0, farthest = 0, n = nums.size();
        for (int i = 0; i < n - 1; i++) {
            farthest = max(farthest, i + nums[i]);
            if (i == end) {
                ans++;
                end = farthest;
            }
        }
        return ans;
    }
};
```

**复杂度**: 时间 O(N) | 空间 O(1)

## 0131 排序 — 合并区间

**题目**: [56. 合并区间](https://leetcode.cn/problems/merge-intervals/)

**分类**: 排序 / 数组

**思路**: 按区间左端点排序，维护当前区间 `[L, R]`。遍历下一个区间时，若其左端点 ≤ R，则更新 R = max(R, 右端点) 实现合并；否则将当前区间加入答案，开始新区间。

**代码 (Python)**:
```python
class Solution:
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        intervals.sort(key=lambda x: x[0])
        ans = []
        for l, r in intervals:
            if not ans or l > ans[-1][1]:
                ans.append([l, r])
            else:
                ans[-1][1] = max(ans[-1][1], r)
        return ans
```

**复杂度**: 时间 O(N log N) | 空间 O(log N)

## 0132 Floyd — 寻找重复数

**题目**: [287. 寻找重复数](https://leetcode.cn/problems/find-the-duplicate-number/)

**分类**: 快慢指针 / 环检测 / 二分

**思路**: 将数组视为链表——`i → nums[i]`，因为存在重复数，所以链表必有环。使用 Floyd 快慢指针算法：快慢指针相遇后，将慢指针重置到起点，与快指针同步移动，相遇点即为环入口（重复数）。

**代码 (Python)**:
```python
class Solution:
    def findDuplicate(self, nums: List[int]) -> int:
        slow = fast = nums[0]
        while True:
            slow = nums[slow]
            fast = nums[nums[fast]]
            if slow == fast:
                break
        slow = nums[0]
        while slow != fast:
            slow = nums[slow]
            fast = nums[fast]
        return slow
```

**复杂度**: 时间 O(N) | 空间 O(1)

## 0133 前缀树变体 — 单词搜索 II

**题目**: [212. 单词搜索 II](https://leetcode.cn/problems/word-search-ii/)

**分类**: 字典树 / 回溯 / 剪枝

**思路**: 先将所有目标单词构建 Trie，在棋盘上进行 DFS 搜索时同步遍历 Trie。若当前 Trie 节点标记为单词末尾则加入结果（并取消标记避免重复）。利用 Trie 剪枝：若当前 Trie 节点没有对应字符的子节点则直接返回。

**代码 (C++)**:
```cpp
class Solution {
    struct Node {
        Node* ch[26] = {};
        string* word = nullptr;
    };
    Node* root = new Node();
    vector<string> ans;

    void build(vector<string>& words) {
        for (auto& w : words) {
            Node* p = root;
            for (char c : w) {
                int i = c - 'a';
                if (!p->ch[i]) p->ch[i] = new Node();
                p = p->ch[i];
            }
            p->word = &w;
        }
    }

    void dfs(vector<vector<char>>& b, int i, int j, Node* p) {
        char c = b[i][j];
        if (c == '.' || !p->ch[c-'a']) return;
        p = p->ch[c-'a'];
        if (p->word) { ans.push_back(*p->word); p->word = nullptr; }
        b[i][j] = '.';
        int d[5] = {-1,0,1,0,-1};
        for (int k = 0; k < 4; k++) {
            int x = i + d[k], y = j + d[k+1];
            if (x >= 0 && x < b.size() && y >= 0 && y < b[0].size())
                dfs(b, x, y, p);
        }
        b[i][j] = c;
    }

public:
    vector<string> findWords(vector<vector<char>>& board, vector<string>& words) {
        build(words);
        for (int i = 0; i < board.size(); i++)
            for (int j = 0; j < board[0].size(); j++)
                dfs(board, i, j, root);
        return ans;
    }
};
```

**复杂度**: 时间 O(M × N × 4^L) | 空间 O(W × L)

## 0134 单调队列 — 滑动窗口最大值

**题目**: [239. 滑动窗口最大值](https://leetcode.cn/problems/sliding-window-maximum/)

**分类**: 队列 / 单调队列 / 双端队列

**思路**: 维护一个递减的双端队列，队首始终为当前窗口的最大值。窗口右移时，从队尾移除所有小于新元素的元素，再将新元素入队；若队首元素移出窗口则从队首移除。

**代码 (Python)**:
```python
class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        dq = collections.deque()
        ans = []
        for i, x in enumerate(nums):
            while dq and nums[dq[-1]] <= x:
                dq.pop()
            dq.append(i)
            if dq[0] == i - k:
                dq.popleft()
            if i >= k - 1:
                ans.append(nums[dq[0]])
        return ans
```

**复杂度**: 时间 O(N) | 空间 O(K)

## 0135 动态规划 — 编辑距离

**题目**: [72. 编辑距离](https://leetcode.cn/problems/edit-distance/)

**分类**: 字符串 / 动态规划

**思路**: `dp[i][j]` 表示 word1 前 i 个字符转变成 word2 前 j 个字符的最少操作数。转移：若字符相等 `dp[i][j] = dp[i-1][j-1]`；否则取增、删、改三种操作的最小值 +1。

**代码 (Python)**:
```python
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        m, n = len(word1), len(word2)
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(m + 1): dp[i][0] = i
        for j in range(n + 1): dp[0][j] = j
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if word1[i-1] == word2[j-1]:
                    dp[i][j] = dp[i-1][j-1]
                else:
                    dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])
        return dp[m][n]
```

**复杂度**: 时间 O(MN) | 空间 O(MN) → 可优化至 O(N)
