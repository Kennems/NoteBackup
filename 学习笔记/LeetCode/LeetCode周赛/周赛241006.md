## [Q1-3309. 连接二进制表示可形成的最大数值](https://leetcode.cn/problems/maximum-possible-number-by-binary-concatenation/)

及时复习Python基础语法

###  题目大意

给定一个长度为 3 的整数数组 `nums`，将数组中的所有元素的 **二进制表示** 以某种顺序连接起来，形成一个二进制字符串。返回可以通过这种方式形成的最大数值。每个数字的二进制表示不能有前导零。

```py
class Solution:
    def maxGoodNumber(self, nums: List[int]) -> int:
        res = 0
        
        for p in permutations(nums):
            b = ''.join(bin(num)[2:] for num in p)
            v = int(b, 2)
            res = max(res, v)
        
        return res
```

## [Q2-3310. 移除可疑的方法](https://leetcode.cn/problems/remove-methods-from-project/)

### 1. 题目大意

你负责维护一个项目，该项目包含 `n` 个方法，编号从 0 到 n-1。给定两个整数 `n` 和 `k`，以及一个二维数组 `invocations`，其中 `invocations[i] = [a_i, b_i]` 表示方法 `a_i` 调用了方法 `b_i`。

已知方法 `k` 存在一个 bug，因此方法 `k` 以及它直接或间接调用的所有方法都被视为 **可疑方法**，需要从项目中移除。只有当这些可疑方法没有被项目中其他非可疑方法调用时，才能被移除。

要求返回一个数组，表示移除所有可疑方法后剩余的所有方法。如果无法移除所有可疑方法，则返回所有方法。输出可以是任意顺序。

### 2. 实现思路
1. **构建调用图**：首先，根据 `invocations` 建立方法之间的调用关系，构建一个邻接表（调用图）。对于每个 `a_i, b_i`，记录 `a_i` 调用了 `b_i`。
   
2. **标记可疑方法**：从方法 `k` 开始，使用广度优先搜索（BFS）或深度优先搜索（DFS）遍历，标记所有与方法 `k` 直接或间接相关的可疑方法。可以使用一个 `set` 存储所有可疑的方法。

3. **检查是否可以移除**：对于每一条调用关系 `[a_i, b_i]`，如果一个非可疑方法 `a_i` 调用了一个可疑方法 `b_i`，那么这些可疑方法不能被移除，因此返回所有方法。如果没有这样的情况，表示可疑方法可以安全移除。

4. **构建结果**：最后返回未被标记为可疑的所有方法作为结果。

### 代码实现：
```python
class Solution:
    def remainingMethods(self, n: int, k: int, invocations: List[List[int]]) -> List[int]:
        # 建立调用关系的图
        g = defaultdict(list)
        for a, b in invocations:
            g[a].append(b)

        # BFS 标记所有可疑方法
        q = deque([k])
        st = set()  # 存储所有可疑方法
        while q:
            h = q.popleft()
            if h in st:
                continue
            st.add(h)
            for nx in g[h]:
                q.append(nx)

        # 检查是否存在非可疑方法调用可疑方法的情况
        for a, b in invocations:
            if b in st and a not in st:
                return list(range(n))  # 如果存在这种情况，返回所有方法

        # 返回未被标记为可疑的方法
        return [i for i in range(n) if i not in st]
```



## [Q4-3312. 查询排序后的最大公约数](https://leetcode.cn/problems/sorted-gcd-pair-queries/)

### 1. 题目大意
给定一个长度为 `n` 的整数数组 `nums`，以及一个整数数组 `queries`，我们需要查询所有满足 `0 <= i < j < n` 的数对 `(nums[i], nums[j])` 的最大公约数（gcd），并将这些 gcd 值升序排列构成 `gcdPairs` 数组。对于每个查询 `queries[i]`，返回 `gcdPairs` 中对应下标为 `queries[i]` 的值。

要求返回一个整数数组 `answer`，其中 `answer[i]` 是 `gcdPairs[queries[i]]` 的值。

- gcd(a, b) 表示 a 和 b 的最大公约数。

### 2. 实现思路

1. **统计每个数的频率**：使用 `Counter` 来统计 `nums` 中每个数的出现频率，这对于后续计算 gcd 值的次数很有帮助。

2. **计算 gcd 值的频率**：
   - 从最大的数开始，逐个枚举 gcd 值 `g`。对于每个 `g`，计算有多少对数 `(nums[i], nums[j])` 的 gcd 值等于 `g`。
   - 利用倍数的特性，累加所有能够整除 `g` 的数对的数量。如果该数对的 gcd 是 `g` 的倍数，则将其从当前 gcd 的计数中移除。

3. **构建 gcdPairs 列表**：
   - 对于每个 `g`，如果其对应的 gcd 对数大于 0，则将其累加到前缀和列表中，并记录 `g` 对应的累计位置。
   - 通过二分查找快速定位每个查询 `queries[i]` 对应的 gcd 值。

4. **二分查找**：
   - 利用前缀和数组 `pre` 对每个查询 `queries[i]` 进行二分查找，快速获取对应的 gcd 值。

### 代码实现：
```python
class Solution:
    def gcdValues(self, nums: List[int], queries: List[int]) -> List[int]:
        # 统计每个数的出现频率
        f = Counter(nums)
        mx = max(nums)
        gc = [0] * (mx + 1)  # 存储 gcd pair 的数量

        # 从大到小计算每个 gcd 值的数对数量
        for g in range(mx, 0, -1):
            # 统计所有能够整除 g 的数的频率之和
            c = sum(f[i] for i in range(g, mx + 1, g))
            if c >= 2:
                # 计算数对数量
                gc[g] = c * (c - 1) // 2
                # 移除 gcd 为 g 的倍数的数对
                for m in range(2 * g, mx + 1, g):
                    gc[g] -= gc[m]

        # 构建前缀和 gcd 值数组
        pre = []  # 前缀和及其对应的 gcd 值
        s = 0
        for g in range(1, mx + 1):
            if gc[g] > 0:
                s += gc[g]
                pre.append((s, g))  # 记录前缀和与 gcd 值

        # 处理 queries，通过二分查找返回对应的 gcd 值
        res = []
        for q in queries:
            idx = bisect_left(pre, (q + 1, float('inf')))  # 寻找前缀和位置
            res.append(pre[idx][1])  # 返回对应的 gcd 值

        return res
```
