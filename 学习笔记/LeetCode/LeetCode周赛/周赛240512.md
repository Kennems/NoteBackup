## 第一题 [3146. 两个字符串的排列差](https://leetcode.cn/problems/permutation-difference-between-two-strings/)

**题目描述**

给定两个字符串 `s` 和 `t`，每个字符串中的字符都不重复，且 `t` 是 `s` 的一个排列。排列差定义为 `s` 和 `t` 中每个字符在两个字符串中位置的绝对差值之和。

示例：
- s = "abc", t = "bac" → 输出 2（|0-1| + |1-0| + |2-2| = 2）
- s = "abcde", t = "edbac" → 输出 12

**思路**

用哈希表记录 `s` 中每个字符的下标，然后遍历 `t`，累加每个字符在 `t` 中的位置与在 `s` 中的位置的绝对差值。由于字符集仅为小写字母，也可用长度为 26 的数组替代哈希表。

**代码**

```python
class Solution:
    def findPermutationDifference(self, s: str, t: str) -> int:
        d = {c: i for i, c in enumerate(s)}
        return sum(abs(d[c] - i) for i, c in enumerate(t))
```

**复杂度分析**

- 时间复杂度: O(n)，n 为字符串长度
- 空间复杂度: O(|Σ|)，Σ 为字符集大小（最多 26）

## 第二题 [3147. 从魔法师身上吸取的最大能量](https://leetcode.cn/problems/taking-maximum-energy-from-the-mystic-dungeon/)

**题目描述**

n 个魔法师站成一排，每个魔法师有能量值 `energy[i]`（可能为负）。从魔法师 `i` 处吸收能量后，会被传送到 `(i + k)` 处，重复直到越界。求能获得的最大总能量。

示例：
- energy = [5,2,-10,-5,1], k = 3 → 输出 3（选择下标 1，得 2 + 1 = 3）
- energy = [-2,-3,-1], k = 2 → 输出 -1

**思路**

从后往前考虑。对于每个可能的终点位置 `i`（范围 `n-k` 到 `n-1`），向前以 k 为步长累加能量，维护最大值。相当于对每个模 k 同余类求最大后缀和。因为跳跃步长固定为 k，每个索引所属的同余类（模 k）独立，只需分别计算每个类的最大后缀和。

**代码**

```python
class Solution:
    def maximumEnergy(self, energy: List[int], k: int) -> int:
        n = len(energy)
        ans = -inf
        for i in range(n - k, n):
            s = 0
            for j in range(i, -1, -k):
                s += energy[j]
                ans = max(ans, s)
        return ans
```

**复杂度分析**

- 时间复杂度: O(n)
- 空间复杂度: O(1)

## 第三题 [3148. 矩阵中的最大得分](https://leetcode.cn/problems/maximum-difference-score-in-a-grid/)

**题目描述**

给定一个 m x n 的正整数矩阵 `grid`，从任一单元格开始，可以向右或向下移动到任意单元格（不必相邻），至少移动一次。从 `c1` 移动到 `c2` 的得分为 `c2 - c1`，求最大总得分。

示例：
- `grid = [[9,5,7,3],[8,9,6,1],[6,7,14,3],[2,5,3,1]]` → 输出 9
- `grid = [[4,3,2],[3,2,1]]` → 输出 -1

**思路**

经过若干次移动后，总得分 = `c_k - c_1`，即终点值减起点值。问题转化为：对每个单元格 `(i, j)`，从它上方或左侧的某个单元格出发，到达该点的最大差值。

定义 `f[i][j]` 表示从左上角区域到达 `(i, j)` 的最小单元格值（包括自身），则转移方程：
```
f[i][j] = min(f[i-1][j], f[i][j-1], grid[i][j])
```
以 `(i, j)` 为终点的最大得分为 `grid[i][j] - min(f[i-1][j], f[i][j-1])`，取全局最大值。

注意起点不能是终点，因此不使用 `grid[i][j] - f[i][j]`（这会得到 0 或负数），而是用上方或左侧的最小值来计算。

**代码**

```python
class Solution:
    def maxScore(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        f = [[0] * n for _ in range(m)]
        ans = -inf
        for i in range(m):
            for j in range(n):
                mi = inf
                if i:
                    mi = min(mi, f[i - 1][j])
                if j:
                    mi = min(mi, f[i][j - 1])
                ans = max(ans, grid[i][j] - mi)
                f[i][j] = min(grid[i][j], mi)
        return ans
```

**复杂度分析**

- 时间复杂度: O(m × n)
- 空间复杂度: O(m × n)，可优化为 O(n)（仅保留上一行）

## 第四题 [3149. 找出分数最低的排列](https://leetcode.cn/problems/find-the-minimum-cost-array-permutation/)

**题目描述**

给定数组 `nums`，它是 `[0, 1, ..., n-1]` 的一个排列。对于排列 `perm`，其分数定义为：

```
score(perm) = |perm[0] - nums[perm[1]]| + |perm[1] - nums[perm[2]]| + ... + |perm[n-1] - nums[perm[0]]|
```

返回具有最低分数的排列，若分数相同返回字典序最小的。

示例：
- nums = [1,0,2] → 输出 [0,1,2]，分数 = |0-0| + |1-2| + |2-1| = 2
- nums = [0,2,1] → 输出 [0,2,1]，分数 = |0-1| + |2-2| + |1-0| = 2

**思路**

关键观察：将排列循环左移任意次，分数不变。因此可固定 `perm[0] = 0`，既保证字典序最小（第一个元素为 0 的任何排列都字典序更小），又减少了状态空间。

n ≤ 14，适合状态压缩 DP（记忆化搜索）。

定义 `dfs(mask, pre)`：
- `mask`：已选数字的位掩码（第 i 位为 1 表示已选）
- `pre`：上一个选的数字
- 返回值：从当前状态到完成的最小分数

边界条件：`mask` 全满时返回 `|pre - nums[0]|`（最后一位与第一位形成闭环）。

转移：枚举下一个未选的 `cur`，分数为 `|pre - nums[cur]| + dfs(mask|1<<cur, cur)`，取最小值。

得到最小分数后，用回溯函数 `g(mask, pre)` 按字典序构造具体排列：从 0 开始，每次选择第一个使分数等于 `dfs(mask, pre)` 的 `cur`。

**代码**

```python
class Solution:
    def findPermutation(self, nums: List[int]) -> List[int]:
        n = len(nums)

        @cache
        def dfs(mask: int, pre: int) -> int:
            if mask == (1 << n) - 1:
                return abs(pre - nums[0])
            res = inf
            for cur in range(1, n):
                if not (mask >> cur & 1):
                    nxt = dfs(mask | (1 << cur), cur)
                    res = min(res, abs(pre - nums[cur]) + nxt)
            return res

        ans = []

        def g(mask: int, pre: int):
            ans.append(pre)
            if mask == (1 << n) - 1:
                return
            best = dfs(mask, pre)
            for cur in range(1, n):
                if not (mask >> cur & 1):
                    if abs(pre - nums[cur]) + dfs(mask | (1 << cur), cur) == best:
                        g(mask | (1 << cur), cur)
                        break

        g(1, 0)
        return ans
```

**复杂度分析**

- 时间复杂度: O(n² × 2ⁿ)，总状态数 O(n × 2ⁿ)，每次转移 O(n)
- 空间复杂度: O(n × 2ⁿ)，用于记忆化数组
