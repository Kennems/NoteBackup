# 操作系统(1)

## 应用视角的操作系统

操作系统是管理计算机硬件与软件资源的系统软件，同时也是计算机系统的内核与基石。从应用开发者的视角看，操作系统提供了以下核心抽象：

### 进程管理

```c
// fork: 创建子进程
#include <unistd.h>
pid_t pid = fork();
if (pid == 0) {
    // 子进程
    printf("child process\n");
} else {
    // 父进程
    printf("parent process, child pid = %d\n", pid);
}
```

**关键概念**：
| 概念    | 说明                                    |
| ------- | --------------------------------------- |
| PID     | 进程唯一标识符                           |
| fork()  | 创建子进程，复制父进程的地址空间          |
| exec()  | 替换当前进程的代码和数据                  |
| exit()  | 终止进程                                |
| wait()  | 父进程等待子进程结束                      |

### 内存管理

操作系统的内存管理负责：
- **内存分配与回收**：malloc/free（C）、new/delete（C++）
- **虚拟内存**：每个进程拥有独立的地址空间
- **页面置换**：LRU、FIFO 等算法管理物理内存与磁盘之间的交换
- **内存保护**：防止进程访问其他进程的内存

### 文件系统

操作系统的文件系统负责：
- 文件的创建、读取、写入、删除
- 目录结构的组织
- 权限管理（rwx）
- 磁盘空间管理

**常见文件系统**：ext4（Linux）、NTFS（Windows）、APFS（macOS）

### I/O 管理

操作系统通过**设备驱动程序**管理 I/O 设备：
- 块设备（磁盘）
- 字符设备（键盘、串口）
- 网络设备

## 操作系统内核类型

| 类型       | 说明                               | 典型系统              |
| ---------- | ---------------------------------- | --------------------- |
| 宏内核     | 所有模块在内核空间运行，性能高       | Linux、Unix           |
| 微内核     | 最小化内核，大部分服务在用户空间     | MINIX、QNX、seL4      |
| 混合内核   | 结合宏内核和微内核特性               | Windows NT、macOS     |
