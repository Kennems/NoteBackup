# MTProto

Telegram 自研的通信协议，用于客户端与服务器之间的加密通信。

## 核心特性

- **安全性**：端到端加密，多层级加密机制
- **高性能**：针对移动网络优化，低延迟
- **可靠性**：支持弱网环境，断线重连
- **跨平台**：支持 Android、iOS、Desktop、Web 等平台

## AES (Advanced Encryption Standard)

AES（高级加密标准）是 MTProto 中使用的对称加密算法，也是目前**最常见**的对称加密算法。

### 关键特性

| 特性     | 说明                           |
| -------- | ------------------------------ |
| 类型     | 对称加密（加解密使用同一密钥）   |
| 密钥长度 | 128位 / 192位 / 256位（AES-256 最安全） |
| 分组大小 | 128位（16字节）                |
| 工作模式 | ECB / CBC / CTR / GCM 等        |

### 常见工作模式

| 模式   | 特点                               |
| ------ | ---------------------------------- |
| ECB    | 简单但最不安全（相同明文→相同密文） |
| CBC    | 链式加密，前一密文块影响后一块，需要 IV |
| CTR    | 流式加密，计数器模式，支持并行      |
| GCM    | **推荐**，同时提供加密和认证（AEAD） |

### AES 加解密流程

```
明文 + 密钥 → [AES 加密] → 密文
密文 + 密钥 → [AES 解密] → 明文
```

### MTProto 中的加密层次

1. **传输层加密**：客户端与服务器之间的所有通信都经过加密
2. **端到端加密**（Secret Chat）：只有通信双方能解密消息，服务器也无法读取
3. **密钥协商**：使用 Diffie-Hellman 密钥交换协议生成共享密钥
