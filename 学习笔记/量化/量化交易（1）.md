# 量化交易（1）

## 什么是量化交易？

量化交易是指以先进的数学模型替代人为的主观判断，利用计算技术从庞大的历史数据中海选出能带来超额收益的多种"大概率"事件以制定策略，极大地减少了投资者情绪波动的影响，避免在市场极度狂热或悲观的情况下作出非理性的投资策略。

### 量化交易的核心要素

1. **模型驱动** — 基于数学、统计学模型而非主观判断
2. **数据驱动** — 依赖大量历史数据和实时数据
3. **系统化执行** — 自动执行交易信号，避免人为干预
4. **风险管理** — 严格的止损、仓位控制和资金管理
5. **回测验证** — 策略上线前需经过充分的历史回测

### 量化交易的优缺点

| 优点 | 缺点 |
|------|------|
| 消除情绪干扰 | 模型过拟合风险 |
| 可同时监控多个市场 | 黑天鹅事件无法预测 |
| 回测验证策略有效性 | 技术门槛高 |
| 严格的纪律性 | 市场环境变化导致策略失效 |
| 可扩展性强 | 需要持续维护和优化 |

### 常见量化策略分类

- **趋势跟踪** — 均线策略、海龟交易法则
- **均值回归** — 配对交易、布林带策略
- **统计套利** — 协整关系、价差交易
- **事件驱动** — 财报发布、新闻情绪
- **机器学习** — LSTM预测、XGBoost分类

## 量化交易开发流程

```
数据获取 -> 数据清洗 -> 策略编写 -> 策略回测 -> 策略优化 -> 实盘交易
```

## 数据清洗

原始数据通常存在缺失值、异常值、复权问题等，需要清洗后才能用于策略开发。

### 基本清洗流程

```python
import pandas as pd
import numpy as np

def clean_stock_data(df: pd.DataFrame) -> pd.DataFrame:
    """清洗股票日线数据"""
    df = df.copy()

    # 1. 排序：按时间升序
    if 'trade_date' in df.columns:
        df['trade_date'] = pd.to_datetime(df['trade_date'])
        df = df.sort_values('trade_date')

    # 2. 处理缺失值
    print(f"缺失值数量:\n{df.isnull().sum()}")

    # 向前填充（非交易日的缺失）
    df = df.fillna(method='ffill')

    # 或直接删除缺失行
    df = df.dropna()

    # 3. 去重
    df = df.drop_duplicates(subset=['trade_date'])

    # 4. 过滤异常值（如价格 <= 0）
    for col in ['open', 'high', 'low', 'close']:
        if col in df.columns:
            df = df[df[col] > 0]

    # 5. 重设索引
    df = df.reset_index(drop=True)

    return df


# 示例使用
raw_data = {
    'trade_date': ['2023-01-01', '2023-01-02', '2023-01-03', '2023-01-05'],
    'close': [10.0, np.nan, 10.5, 11.0],
    'volume': [10000, 12000, None, 15000]
}
df_raw = pd.DataFrame(raw_data)
df_clean = clean_stock_data(df_raw)
print(df_clean)
```

### 计算技术指标

```python
def add_technical_indicators(df: pd.DataFrame) -> pd.DataFrame:
    """添加常用技术指标"""
    df = df.copy()

    # 移动平均线
    df['MA5'] = df['close'].rolling(window=5).mean()
    df['MA20'] = df['close'].rolling(window=20).mean()
    df['MA60'] = df['close'].rolling(window=60).mean()

    # 布林带
    df['BB_middle'] = df['close'].rolling(window=20).mean()
    df['BB_std'] = df['close'].rolling(window=20).std()
    df['BB_upper'] = df['BB_middle'] + 2 * df['BB_std']
    df['BB_lower'] = df['BB_middle'] - 2 * df['BB_std']

    # RSI（相对强弱指标）
    delta = df['close'].diff()
    gain = delta.where(delta > 0, 0.0)
    loss = (-delta).where(delta < 0, 0.0)
    avg_gain = gain.rolling(window=14).mean()
    avg_loss = loss.rolling(window=14).mean()
    rs = avg_gain / avg_loss
    df['RSI'] = 100 - (100 / (1 + rs))

    # MACD
    ema12 = df['close'].ewm(span=12).mean()
    ema26 = df['close'].ewm(span=26).mean()
    df['MACD'] = ema12 - ema26
    df['MACD_signal'] = df['MACD'].ewm(span=9).mean()
    df['MACD_hist'] = df['MACD'] - df['MACD_signal']

    # 日收益率
    df['daily_return'] = df['close'].pct_change()

    return df
```

## 策略编写

常见的量化交易策略示例。

### 策略1：双均线交叉策略（Moving Average Crossover）

最经典的趋势跟踪策略：短期均线上穿长期均线时买入，下穿时卖出。

```python
import pandas as pd
import numpy as np
import yfinance as yf

def ma_crossover_strategy(data: pd.DataFrame, short_window=5, long_window=20):
    """双均线交叉策略"""
    df = data.copy()

    # 计算短期和长期均线
    df['MA_short'] = df['close'].rolling(window=short_window).mean()
    df['MA_long'] = df['close'].rolling(window=long_window).mean()

    # 生成信号：1=买入，-1=卖出，0=持有
    df['signal'] = 0
    df.loc[df['MA_short'] > df['MA_long'], 'signal'] = 1
    df.loc[df['MA_short'] <= df['MA_long'], 'signal'] = -1

    # 计算实际持仓（信号变化时才交易）
    df['position'] = df['signal'].diff().fillna(0)
    df.loc[df['position'] != 0, 'trade'] = df['signal']
    df['trade'] = df['trade'].fillna(0)

    return df

# 示例
data = yf.download('AAPL', start='2022-01-01', end='2023-12-31')
result = ma_crossover_strategy(data, short_window=5, long_window=20)
print(result[['close', 'MA_short', 'MA_long', 'signal', 'trade']].tail(10))
```

### 策略2：动量策略（Momentum Strategy）

买入过去一段时间涨幅最大的股票，卖出涨幅最小的股票。

```python
def momentum_strategy(data: pd.DataFrame, lookback=60, top_pct=0.2):
    """
    动量策略
    lookback: 回顾期
    top_pct: 选取前百分之多少的股票
    """
    # 计算过去lookback天的累计收益率
    returns = data['close'].pct_change(lookback)

    # 生成信号
    df = data.copy()
    df['momentum'] = returns
    df['signal'] = 0

    # 动量为正时持有，为负时空仓
    df.loc[df['momentum'] > 0, 'signal'] = 1
    df.loc[df['momentum'] <= 0, 'signal'] = -1

    return df
```

### 策略3：均值回归策略（Mean Reversion）

当价格偏离均值过多时，预期价格会回归。

```python
def mean_reversion_strategy(data: pd.DataFrame, window=20, std_mult=2):
    """基于布林带的均值回归策略"""
    df = data.copy()

    # 计算均值与标准差
    df['mean'] = df['close'].rolling(window=window).mean()
    df['std'] = df['close'].rolling(window=window).std()

    df['upper'] = df['mean'] + std_mult * df['std']
    df['lower'] = df['mean'] - std_mult * df['std']

    # 信号：价格触及下轨买入，触及上轨卖出
    df['signal'] = 0
    df.loc[df['close'] < df['lower'], 'signal'] = 1    # 买入信号
    df.loc[df['close'] > df['upper'], 'signal'] = -1   # 卖出信号

    # 回归到均值时平仓
    df.loc[df['close'] >= df['mean'], 'signal'] = 0

    return df
```

### 策略4：海龟交易法则简化版

```python
def turtle_trader_strategy(data: pd.DataFrame, entry_period=20, exit_period=10):
    """简化版海龟交易法则"""
    df = data.copy()

    # 唐奇安通道
    df['entry_high'] = df['high'].rolling(window=entry_period).max()
    df['entry_low'] = df['low'].rolling(window=entry_period).min()
    df['exit_high'] = df['high'].rolling(window=exit_period).max()
    df['exit_low'] = df['low'].rolling(window=exit_period).min()

    # ATR（平均真实波幅）用于止损
    df['tr'] = np.maximum(
        df['high'] - df['low'],
        np.maximum(
            abs(df['high'] - df['close'].shift(1)),
            abs(df['low'] - df['close'].shift(1))
        )
    )
    df['atr'] = df['tr'].rolling(window=14).mean()

    # 信号
    df['signal'] = 0
    df.loc[df['close'] > df['entry_high'].shift(1), 'signal'] = 1
    df.loc[df['close'] < df['entry_low'].shift(1), 'signal'] = -1

    # 止损价
    df['stop_loss'] = df['close'] - 2 * df['atr']

    return df
```

## 策略回测

回测是用历史数据验证策略表现的过程，是量化开发中最关键的环节。

### 手动回测框架

```python
def backtest(df: pd.DataFrame, initial_capital=100000, commission=0.0003):
    """
    简易回测引擎
    df: 必须包含 'close' 和 'signal' 列
    commission: 交易佣金比例（如0.03%）
    """
    result = df.copy()

    # 计算日收益率
    result['daily_return'] = result['close'].pct_change()

    # 策略收益率 = 信号 * 日收益率（不含交易成本）
    result['strategy_return'] = result['signal'].shift(1) * result['daily_return']

    # 扣除交易成本（信号发生变化时）
    result['trade_flag'] = result['signal'].diff().fillna(0) != 0
    trade_cost = result['trade_flag'] * commission * 2  # 买卖各一次
    result['strategy_return'] -= trade_cost

    # 计算净值曲线
    result['strategy_equity'] = initial_capital * (1 + result['strategy_return']).cumprod()
    result['buy_hold_equity'] = initial_capital * (1 + result['daily_return']).cumprod()

    return result


def evaluate_performance(result: pd.DataFrame, risk_free_rate=0.02):
    """评估策略表现"""
    strategy_return = result['strategy_return'].dropna()
    buy_hold_return = result['daily_return'].dropna()

    # 年化收益率
    n = len(strategy_return)
    total_return = (1 + strategy_return).prod() - 1
    annual_return = (1 + total_return) ** (252 / n) - 1

    # 夏普比率
    excess_return = strategy_return - risk_free_rate / 252
    sharpe = np.sqrt(252) * excess_return.mean() / strategy_return.std()

    # 最大回撤
    equity = result['strategy_equity']
    rolling_max = equity.expanding().max()
    drawdown = (equity - rolling_max) / rolling_max
    max_drawdown = drawdown.min()

    # 胜率
    winning_trades = (strategy_return > 0).sum()
    total_trades = (strategy_return != 0).sum()
    win_rate = winning_trades / total_trades if total_trades > 0 else 0

    return {
        '总收益率': f"{total_return:.2%}",
        '年化收益率': f"{annual_return:.2%}",
        '夏普比率': f"{sharpe:.2f}",
        '最大回撤': f"{max_drawdown:.2%}",
        '胜率': f"{win_rate:.2%}",
        '交易次数': total_trades
    }


# 完整回测流程
data = yf.download('AAPL', start='2020-01-01', end='2023-12-31')
signal_df = ma_crossover_strategy(data, short_window=10, long_window=30)
result = backtest(signal_df, initial_capital=100000)
metrics = evaluate_performance(result)

for key, value in metrics.items():
    print(f"{key}: {value}")
```

        ('short_period', 10),
        ('long_period', 30),
    )

    def __init__(self):

## 策略优化

策略优化是在回测基础上调整参数，以提升策略表现的过程。

### 参数网格搜索

```python
from itertools import product

def grid_search(data, short_range, long_range):
    """网格搜索最优均线参数"""
    best_sharpe = -np.inf
    best_params = None
    results = []

    for short_w, long_w in product(short_range, long_range):
        if short_w >= long_w:
            continue

        # 生成信号
        signal_data = ma_crossover_strategy(data, short_window=short_w, long_window=long_w)

        # 回测
        backtest_result = backtest(signal_data, initial_capital=100000)
        metrics = evaluate_performance(backtest_result)

        sharpe = float(metrics['夏普比率'].rstrip('%')) / 100

        results.append({
            'short_window': short_w,
            'long_window': long_w,
            'sharpe': sharpe,
            'total_return': metrics['总收益率'],
            'max_drawdown': metrics['最大回撤']
        })

        if sharpe > best_sharpe:
            best_sharpe = sharpe
            best_params = (short_w, long_w)

    results_df = pd.DataFrame(results)
    return best_params, results_df


# 示例
data = yf.download('AAPL', start='2020-01-01', end='2023-12-31')
best_params, results_df = grid_search(
    data,
    short_range=range(5, 30, 5),
    long_range=range(20, 60, 10)
)
print(f"最优参数: short={best_params[0]}, long={best_params[1]}")
print(results_df.sort_values('sharpe', ascending=False).head(10))
```

### 过拟合的预防

过拟合是量化交易中最大的陷阱，表现为策略在回测中表现极好但在实盘中表现很差。

```python
def walk_forward_validation(data, train_ratio=0.6, val_ratio=0.2):
    """
    滚动前向验证
    - 训练集（60%）：寻找最优参数
    - 验证集（20%）：验证参数稳定性
    - 测试集（20%）：最终评估（仅用一次）
    """
    n = len(data)
    train_end = int(n * train_ratio)
    val_end = int(n * (train_ratio + val_ratio))

    train_data = data.iloc[:train_end]
    val_data = data.iloc[train_end:val_end]
    test_data = data.iloc[val_end:]

    # 在训练集上搜索最优参数
    best_params, _ = grid_search(
        train_data,
        short_range=range(5, 50, 5),
        long_range=range(20, 100, 10)
    )

    # 在验证集上验证
    val_signal = ma_crossover_strategy(
        val_data,
        short_window=best_params[0],
        long_window=best_params[1]
    )
    val_result = backtest(val_signal)
    val_metrics = evaluate_performance(val_result)

    # 在测试集上做最终评估
    test_signal = ma_crossover_strategy(
        test_data,
        short_window=best_params[0],
        long_window=best_params[1]
    )
    test_result = backtest(test_signal)
    test_metrics = evaluate_performance(test_result)

    return {
        'best_params': best_params,
        'validation_metrics': val_metrics,
        'test_metrics': test_metrics
    }


result = walk_forward_validation(data)
print(f"最优参数: {result['best_params']}")
print(f"验证集表现: {result['validation_metrics']}")
print(f"测试集表现: {result['test_metrics']}")
```

### 过拟合的常见预防措施

1. **样本外测试** — 保留部分数据不参与参数优化
2. **滚动前向验证** — 逐步滚动训练/测试窗口
3. **减少参数数量** — 参数越多，过拟合风险越大
4. **正则化** — 对复杂度施加惩罚
5. **蒙特卡洛模拟** — 随机打乱收益率序列，检验策略是否仍然有效
6. **交易成本敏感性分析** — 检验策略在不同佣金水平下的表现

class TradingEngine:
    """交易引擎"""

    def __init__(self, strategy, trader, data_feed, interval=60):
        self.strategy = strategy
        self.trader = trader
        self.data_feed = data_feed
        self.interval = interval  # 运行间隔（秒）
        self.running = False
        self.current_position = 0

    def start(self):
        """启动交易引擎"""
        self.running = True
        self.trader.connect()
        logging.info("交易引擎启动")

        while self.running:
            try:
                self.tick()
                time.sleep(self.interval)
            except KeyboardInterrupt:
                self.stop()
            except Exception as e:
                logging.error(f"运行异常: {e}")
                self.stop()

    def stop(self):
        """停止交易引擎"""
        self.running = False
        logging.info("交易引擎停止")

    def tick(self):
        """每个周期执行"""
        # 1. 获取最新数据
        latest_data = self.data_feed.get_latest_data()

        # 2. 计算信号
        signal = self.strategy.generate_signal(latest_data)
        logging.info(f"当前信号: {signal}")

        # 3. 执行交易
        if signal == 1 and self.current_position <= 0:
            # 买入
            self.trader.place_order('AAPL', 'buy', 100)
            self.current_position = 100
            logging.info("执行买入")

        elif signal == -1 and self.current_position >= 0:
            # 卖出
            self.trader.place_order('AAPL', 'sell', 100)
            self.current_position = 0
            logging.info("执行卖出")

    def get_status(self):
        """获取运行状态"""
        return {
            'running': self.running,
            'position': self.current_position,
            'orders': len(self.trader.order_history),
            'balance': self.trader.get_account_info()
        }

def calculate_position_size(
    capital: float,
    price: float,
    risk_per_trade: float = 0.02,
    stop_loss_pct: float = 0.05
) -> int:
    """
    凯利公式简化版仓位计算
    risk_per_trade: 单笔风险比例（2%）
    stop_loss_pct: 止损比例（5%）
    """
    # 单笔最大亏损金额
    max_loss = capital * risk_per_trade

    # 每股亏损金额
    loss_per_share = price * stop_loss_pct

    # 应买入股数
    shares = int(max_loss / loss_per_share)

    return max(shares, 0)


def calculate_kelly_criterion(win_rate, avg_win, avg_loss):
    """
    凯利公式计算最优仓位比例
    f* = (p * b - q) / b
    p: 胜率, b: 盈亏比, q: 败率
    """
    if avg_loss == 0:
        return 0

    b = avg_win / avg_loss  # 盈亏比
    q = 1 - win_rate
    f = (win_rate * b - q) / b

    # 实际使用1/4凯利，降低风险
    return max(f * 0.25, 0)

avg_loss_pct = 0.05

print(f"建议仓位比例: {kelly_fraction:.2%}")

class RiskManager:
    """风险管理器"""

    def __init__(self, max_drawdown=0.15, max_position_ratio=0.3, max_daily_loss=0.05):
        self.max_drawdown = max_drawdown
        self.max_position_ratio = max_position_ratio
        self.max_daily_loss = max_daily_loss
        self.initial_capital = None
        self.peak_capital = None
        self.daily_loss = 0

    def check_risk(self, account_info, current_price, position_value):
        """检查风险限制"""
        total_asset = account_info['total_asset']

        # 初始化基准
        if self.initial_capital is None:
            self.initial_capital = total_asset
        if self.peak_capital is None:
            self.peak_capital = total_asset

        # 更新峰值
        if total_asset > self.peak_capital:
            self.peak_capital = total_asset

        # 1. 检查最大回撤
        current_drawdown = (self.peak_capital - total_asset) / self.peak_capital
        if current_drawdown >= self.max_drawdown:
            return False, f"触发最大回撤限制: {current_drawdown:.2%}"

        # 2. 检查仓位比例
        position_ratio = position_value / total_asset
        if position_ratio >= self.max_position_ratio:
            return False, f"仓位比例超限: {position_ratio:.2%}"

        # 3. 检查日内最大亏损
        daily_return = (total_asset - self.initial_capital) / self.initial_capital
        if daily_return <= -self.max_daily_loss:
            return False, f"触发日内最大亏损限制: {daily_return:.2%}"

        return True, "风险检查通过"

    def daily_reset(self, current_capital):
        """每日重置"""
        self.initial_capital = current_capital
        self.daily_loss = 0
