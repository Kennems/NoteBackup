### 文本特征提取

```py
def count_demo():
    """
    文本特征抽取
    :return:
    """
    data = ["life is short, i like python",
            "life is too long, i dislike python"]

    transfer = CountVectorizer()
    data_new = transfer.fit_transform(data)
    print("data_new: \n", data_new.toarray())
    print("特征名字：\n", transfer.get_feature_names_out())

    return None
```

`CountVectorizer` 统计每个样本中词语出现的次数（词频），中文文本需要先分词（如 jieba）再使用。

## 特征预处理

通过数学变换将特征数据转换成更适合算法模型的形式。

### 归一化

将原始数据映射到 [0,1] 区间，公式：`X' = (x - min) / (max - min)`，受异常值影响大。

```py
from sklearn.preprocessing import MinMaxScaler

def minmax_demo():
    data = [[90, 2, 10, 40], [60, 4, 15, 45], [75, 3, 13, 46]]
    scaler = MinMaxScaler(feature_range=(0, 1))
    data_new = scaler.fit_transform(data)
    print("归一化结果:\n", data_new)
    return None
```

### 标准化

将原始数据转换为均值为 0、标准差为 1 的分布，公式：`X' = (x - μ) / σ`，受异常值影响小。

```py
from sklearn.preprocessing import StandardScaler

def standard_demo():
    data = [[90, 2, 10, 40], [60, 4, 15, 45], [75, 3, 13, 46]]
    scaler = StandardScaler()
    data_new = scaler.fit_transform(data)
    print("标准化结果:\n", data_new)
    print("均值:\n", scaler.mean_)
    print("方差:\n", scaler.var_)
    return None
```

## 分类算法

### K-近邻算法 (KNN)

通过测量不同特征值之间的距离进行分类，选择 K 个最近邻居投票决定类别。

```py
from sklearn.neighbors import KNeighborsClassifier
from sklearn.model_selection import train_test_split
from sklearn.datasets import load_iris
from sklearn.preprocessing import StandardScaler

def knn_demo():
    iris = load_iris()
    x_train, x_test, y_train, y_test = train_test_split(
        iris.data, iris.target, test_size=0.2, random_state=22)

    # 标准化
    scaler = StandardScaler()
    x_train = scaler.fit_transform(x_train)
    x_test = scaler.transform(x_test)

    estimator = KNeighborsClassifier(n_neighbors=5)
    estimator.fit(x_train, y_train)
    score = estimator.score(x_test, y_test)
    print("KNN 准确率:", score)
    return None
```

KNN 超参数 `n_neighbors`（K 值）通过交叉验证确定，K 越小模型越复杂易过拟合，K 越大模型越简单易欠拟合。

### 朴素贝叶斯

基于贝叶斯定理和特征条件独立假设的分类方法，常用于文本分类。

```py
from sklearn.naive_bayes import MultinomialNB
from sklearn.feature_extraction.text import TfidfVectorizer

def nb_demo():
    # 以新闻分类为例
    from sklearn.datasets import fetch_20newsgroups
    news = fetch_20newsgroups(subset='all')

    x_train, x_test, y_train, y_test = train_test_split(
        news.data, news.target, test_size=0.25)

    transfer = TfidfVectorizer()
    x_train = transfer.fit_transform(x_train)
    x_test = transfer.transform(x_test)

    estimator = MultinomialNB(alpha=1.0)
    estimator.fit(x_train, y_train)
    score = estimator.score(x_test, y_test)
    print("朴素贝叶斯准确率:", score)
    return None
```

优点：发源于古典数学，分类效率稳定；对缺失数据不敏感。缺点：特征独立假设在现实中往往不成立。

## 回归算法

### 线性回归

通过最小化均方误差（MSE）拟合线性模型：`y = wx + b`。

```py
from sklearn.linear_model import LinearRegression

def linear_demo():
    from sklearn.datasets import load_diabetes
    diabetes = load_diabetes()
    x_train, x_test, y_train, y_test = train_test_split(
        diabetes.data, diabetes.target, test_size=0.2, random_state=22)
```

## 模型评估与调优

### 交叉验证

将训练集划分为 K 份，每次用 K-1 份训练、1 份验证，取 K 次结果均值作为最终评估。

### 网格搜索 GridSearchCV

在指定参数范围内自动搜索最优超参数组合，配合交叉验证使用。

```py
from sklearn.model_selection import GridSearchCV

def gridsearch_demo():
    iris = load_iris()
    x_train, x_test, y_train, y_test = train_test_split(
        iris.data, iris.target, test_size=0.2, random_state=22)

    param_grid = {"n_neighbors": [3, 5, 7, 9]}
    estimator = KNeighborsClassifier()
    gs = GridSearchCV(estimator, param_grid, cv=5)
    gs.fit(x_train, y_train)

    print("最优参数:", gs.best_params_)
    print("最优模型:", gs.best_estimator_)
    print("最优分数:", gs.best_score_)
    return None
```

## 深度学习基础

### 感知机与多层感知机

感知机是最简单的神经网络结构，接受多个输入后加权求和，通过激活函数输出。单层感知机只能解决线性可分问题，多层感知机（MLP）引入隐藏层和非线性激活函数后可解决非线性问题。

常用激活函数：
- **Sigmoid**：`f(x) = 1 / (1 + e⁻ˣ)`，输出映射到 (0,1)，适合二分类输出层
- **Tanh**：`f(x) = (eˣ - e⁻ˣ) / (eˣ + e⁻ˣ)`，输出映射到 (-1,1)
- **ReLU**：`f(x) = max(0, x)`，计算简单、缓解梯度消失，目前最常用

### 损失函数与梯度下降

- **均方误差 MSE**：回归任务
- **交叉熵损失 CrossEntropyLoss**：分类任务

梯度下降通过反向传播计算损失对各层参数的梯度，沿梯度反方向更新参数使损失最小化。

### 过拟合与正则化

过拟合表现：训练集表现好、测试集表现差。解决方法：
- L1/L2 正则化（在损失函数中加入权重的范数惩罚）
- Dropout（训练时随机丢弃部分神经元）
- 早停（Early Stopping）
- 数据增强（Data Augmentation）
