# 测试题目

## 题目 1 — 跨文档知识合成与决策备忘（短篇策略写作）

**测试目标**：多文档信息抽取与归纳、摘要与优先级判断、基于证据给出可执行建议、引用质量与格式化能力，考查模型的事实保持、逻辑组织与职业写作能力。

**给模型的题干（可直接复制）**：

> 阅读下面提供的若干文档（或链接）。为公司 CTO 撰写一份 **300–400 字** 的决策备忘（面向技术/产品领导），要求包含：
>
> 1. 3–5 条核心要点（每条一句话）——要准确反映文档证据；
> 2. 基于以上证据给出 **三条具体可操作的建议**（每条建议包含：主要行动、大致资源估计（人力/时间/预算）、一个可衡量的指标）；
> 3. 每条建议附 1–2 条实施风险与缓解措施；
> 4. 在文末以 APA 样式列出模型依据的 **至少 3 条不同来源**（新闻、行业报告、公司公告等），每条注明发布日期与作者/机构。
>     输出要求：返回一个 JSON 对象：`{"summary":[...],"recommendations":[{...},{...},{...}],"citations":[...],"word_count":N}`，并确保 `word_count` 在 300–400 字之间。

**输入/输出格式**：如上 JSON。评测方负责把真实文档文本或链接放到 prompt 前面。

**评分细则（满分 100）**：

- 要点准确性（30）——是否覆盖并准确反映每篇文档的核心事实。
- 建议的可行性与具体性（30）——是否可执行，是否给出资源/时间/预算估计与衡量指标。
- 风险识别与缓解（15）——是否识别主要风险并给出可操作缓解措施。
- 引用质量与格式（15）——来源多样性、日期正确、APA 格式或类似规范。
- 文体与篇幅控制（10）——是否为 CTO 定制、语言精练、字数 300–400。

**示例（要点 / 推荐答案要点）**：

- 文档 A：监管趋严（隐私合规要求增强）
- 文档 B：行业竞争加剧（两个竞品推出相似功能）
- 文档 C：用户隐私敏感度上升（调查显示 60% 用户在意数据出口）
   推荐示例（简短）：三条建议可能是：① 优先做合规审计并上报资源（3 周，小团队 2 人，指标：合规缺陷数）；② 推出隐私优先版本（MVP 8 周，预算 X 万），指标：隐私设置启用率；③ 市场沟通策略（4 周），指标：用户信任度提升 10%。

**评测注意**：对事实类主张需人工或借助检索核验是否与原文一致；引用至少一条需与备忘中关键断言直接对应。

import threading, random, time

class LRUCache:
    """线程安全的 LRU 缓存（哈希表 + 双向链表）"""
    class Node:
        __slots__ = ('key','val','prev','next')
        def __init__(self, key, val):
            self.key = key; self.val = val; self.prev = None; self.next = None

    def __init__(self, capacity: int):
        if capacity <= 0:
            raise ValueError("capacity must be > 0")
        self.capacity = capacity
        self.map = {}                # key -> Node
        # dummy head/tail to简化边界处理
        self.head = self.Node(None, None)
        self.tail = self.Node(None, None)
        self.head.next = self.tail
        self.tail.prev = self.head
        self.lock = threading.Lock()  # 并发控制：单一互斥锁（粗粒度）

    # ---- internal helpers (must be called with lock held) ----
    def _add_to_head(self, node):
        node.next = self.head.next
        node.prev = self.head
        self.head.next.prev = node
        self.head.next = node

    def _remove_node(self, node):
        node.prev.next = node.next
        node.next.prev = node.prev
        node.prev = node.next = None

    def _move_to_head(self, node):
        self._remove_node(node)
        self._add_to_head(node)

    def _pop_tail(self):
        if self.tail.prev is self.head:
            return None
        node = self.tail.prev
        self._remove_node(node)
        return node

    # ---- public API ----
    def get(self, key):
        """返回 value 或 None。如果找到则提升为最近使用"""
        with self.lock:
            node = self.map.get(key)
            if not node:
                return None
            self._move_to_head(node)
            return node.val

    def put(self, key, value):
        """插入或更新键值；如超容量则淘汰最久未使用项"""
        with self.lock:
            node = self.map.get(key)
            if node:
                node.val = value
                self._move_to_head(node)
                return
            node = self.Node(key, value)
            self.map[key] = node
            self._add_to_head(node)
            if len(self.map) > self.capacity:
                tail = self._pop_tail()
                if tail:
                    del self.map[tail.key]

        with self.lock:
            return len(self.map)

            # traverse forward
            seen = set()
            cur = self.head.next
            count = 0
            while cur is not self.tail:
                if id(cur) in seen:
                    return False, "cycle detected"
                seen.add(id(cur))
                count += 1
                cur = cur.next
            if count != len(self.map):
                return False, f"count mismatch: list {count} vs map {len(self.map)}"
            # check map nodes are present in seen
            for k,node in list(self.map.items()):
                if id(node) not in seen:
                    return False, f"node for key {k} not in list"

1. 实现思路与复杂度分析
该 LRUCache 实现结合了两种数据结构以达到 O(1) 的平均时间复杂度：
哈希表 (Python dict): 用于存储键和对应双向链表节点的映射 (self.cache)。这使得我们能够以 O(1) 的平均时间复杂度通过键快速定位到节点。
双向链表: 用于维护数据的访问顺序。链表头部代表“最近使用”（Most Recently Used），尾部代表“最少使用”（Least Recently Used）。对链表的头部和尾部进行增删操作，以及移动一个已知节点到头部的操作，时间复杂度均为 O(1)。
get(key): 通过哈希表 O(1) 找到节点，然后将该节点移动到链表头部（O(1) 操作），总复杂度为 O(1)。
put(key, value):
如果键已存在，通过哈希表 O(1) 找到节点，更新其值，并移动到链表头部（O(1)）。
如果键不存在，创建一个新节点并添加到链表头部（O(1)）。
如果超出容量，则移除链表尾部节点（O(1)）并从哈希表中删除对应的键（O(1)）。
总复杂度为 O(1)。
空间复杂度: O(capacity)，因为哈希表和双向链表最多存储 capacity 个元素。
2. 并发控制策略
锁的粒度: 实现采用了一个单一的互斥锁 (threading.Lock) 来保护对 LRUCache 实例的所有访问。这是一种 粗粒度锁 策略。任何需要读取或修改内部状态（哈希表和双向链表）的公共方法 (get, put, size) 在执行前都必须获取这个锁，在执行完毕后释放。
策略优势: 这种方法的优点是实现简单且能有效保证线程安全。由于所有操作都是互斥的，它能从根本上杜绝因并发读写导致的数据结构不一致（如链表指针错乱、缓存数量与实际不符等）的竞态条件。
死锁避免: 由于整个类只使用了一把锁，线程在任何时候最多只会尝试获取这一个锁资源，永远不会出现一个线程持有锁A等待锁B，而另一个线程持有锁B等待锁A的经典死锁场景。因此，该设计天然地避免了死锁。

import threading
import unittest
import time
import random

class LRUCache:
    """
    A thread-safe Least Recently Used (LRU) Cache.

    This implementation uses a hash map for O(1) lookups and a
    doubly linked list to maintain the order of items.

    Concurrency Strategy:
    A single lock (`threading.Lock`) is used to protect all read and write
    operations, ensuring that the internal state (both the dictionary and
    the linked list) remains consistent under concurrent access. This is a
    coarse-grained locking approach that is simple and avoids deadlocks.
    """
    class _Node:
        """Node for the doubly linked list."""
        def __init__(self, key, value):
            self.key = key
            self.value = value
            self.prev = None
            self.next = None

    def __init__(self, capacity: int):
        if capacity <= 0:
            raise ValueError("Capacity must be a positive integer.")
        self.capacity = capacity
        self.cache = {}
        self.lock = threading.Lock()

        # Dummy head and tail nodes to simplify list operations
        self.head = self._Node(0, 0)
        self.tail = self._Node(0, 0)
        self.head.next = self.tail
        self.tail.prev = self.head

    def _remove_node(self, node: _Node):
        """Removes a node from the linked list."""
        prev_node = node.prev
        next_node = node.next
        prev_node.next = next_node
        next_node.prev = prev_node

    def _add_to_head(self, node: _Node):
        """Adds a node right after the head."""
        node.next = self.head.next
        node.prev = self.head
        self.head.next.prev = node
        self.head.next = node

    def _move_to_head(self, node: _Node):
        """Moves an existing node to the head of the list."""
        self._remove_node(node)
        self._add_to_head(node)

    def get(self, key):
        """
        Retrieves an item from the cache. Returns None if not found.
        Time complexity: O(1) on average.
        """
        with self.lock:
            if key not in self.cache:
                return None
            
            node = self.cache[key]
            self._move_to_head(node)
            return node.value

    def put(self, key, value):
        """
        Adds or updates an item in the cache. If the cache is full,
        it evicts the least recently used item.
        Time complexity: O(1) on average.
        """
        with self.lock:
            if key in self.cache:
                node = self.cache[key]
                node.value = value
                self._move_to_head(node)
            else:
                new_node = self._Node(key, value)
                self.cache[key] = new_node
                self._add_to_head(new_node)

                if len(self.cache) > self.capacity:
                    # Evict the least recently used item (at the tail)
                    lru_node = self.tail.prev
                    self._remove_node(lru_node)
                    del self.cache[lru_node.key]

    def size(self) -> int:
        """
        Returns the current number of items in the cache.
        """
        with self.lock:
            return len(self.cache)

        """
        Initialize the LRU Cache with given capacity.
        Uses a hash map and doubly linked list for O(1) operations.
        """
        if capacity <= 0:
            raise ValueError("Capacity must be positive")
        self.capacity = capacity
        self.cache = {}  # key to Node
        self.head = Node(0, 0)  # dummy head
        self.tail = Node(0, 0)  # dummy tail
        self.head.next = self.tail
        self.tail.prev = self.head
        self._size = 0
        self.lock = threading.Lock()  # For thread safety

    def _add_node(self, node):
        """Add node right after head (most recent)."""
        node.prev = self.head
        node.next = self.head.next
        self.head.next.prev = node
        self.head.next = node

    def _remove_node(self, node):
        """Remove node from the list."""
        prev_node = node.prev
        next_node = node.next
        prev_node.next = next_node
        next_node.prev = prev_node

    def _move_to_head(self, node):
        """Move node to most recent position."""
        self._remove_node(node)
        self._add_node(node)

    def get(self, key):
        """
        Get the value for key if exists, move to most recent.
        Returns None if not found.
        Average O(1) time.
        """
        with self.lock:
            if key not in self.cache:
                return None
            node = self.cache[key]
            self._move_to_head(node)
            return node.value

    def put(self, key, value):
        """
        Put key-value, update if exists, evict LRU if over capacity.
        Average O(1) time.
        """
        with self.lock:
            if key in self.cache:
                node = self.cache[key]
                node.value = value
                self._move_to_head(node)
            else:
                new_node = Node(key, value)
                self.cache[key] = new_node
                self._add_node(new_node)
                self._size += 1
                if self._size > self.capacity:
                    # Evict LRU (tail.prev)
                    lru = self.tail.prev
                    self._remove_node(lru)
                    del self.cache[lru.key]
                    self._size -= 1

    def size(self):
        """Return current size."""
        with self.lock:
            return self._size

class Node:
    """双向链表节点"""
    def __init__(self, key, value):
        self.key = key
        self.value = value
        self.prev = None
        self.next = None

class LRUCache:
    """线程安全的LRU缓存实现"""
    def __init__(self, capacity: int):
        self.capacity = capacity
        self.size = 0
        self.cache = dict()  # key -> Node
        # 哨兵节点简化边界处理
        self.head = Node(None, None)
        self.tail = Node(None, None)
        self.head.next = self.tail
        self.tail.prev = self.head
        self.lock = threading.RLock()  # 可重入锁支持嵌套调用

    def _move_to_head(self, node: Node):
        """将节点移动到链表头部（最近使用）"""
        # 移除当前节点
        node.prev.next = node.next
        node.next.prev = node.prev
        # 插入头部
        node.next = self.head.next
        node.prev = self.head
        self.head.next.prev = node
        self.head.next = node

    def _remove_tail(self) -> Node:
        """移除尾部节点（最久未使用）"""
        node = self.tail.prev
        node.prev.next = self.tail
        self.tail.prev = node.prev
        return node

    def get(self, key):
        """获取键值，不存在返回None"""
        with self.lock:
            if key not in self.cache:
                return None
            node = self.cache[key]
            self._move_to_head(node)  # 访问后更新为最近使用
            return node.value

    def put(self, key, value):
        """插入或更新键值对"""
        with self.lock:
            if key in self.cache:
                # 更新已有节点
                node = self.cache[key]
                node.value = value
                self._move_to_head(node)
            else:
                # 创建新节点
                new_node = Node(key, value)
                self.cache[key] = new_node
                # 插入头部
                new_node.next = self.head.next
                new_node.prev = self.head
                self.head.next.prev = new_node
                self.head.next = new_node
                self.size += 1
                # 超过容量则删除尾部
                if self.size > self.capacity:
                    tail_node = self._remove_tail()
                    del self.cache[tail_node.key]
                    self.size -= 1

    def size(self):
        """返回当前缓存大小"""
        with self.lock:
            return self.size
