# Multisim

NI Multisim 是一款基于 SPICE 的电路仿真与设计软件，广泛应用于电子工程教学与原型设计。以下笔记覆盖 Multisim 的核心功能与操作流程。

## 界面概览

| 区域 | 说明 |
|------|------|
| **菜单栏** | 文件、编辑、视图、放置、仿真、传输、工具、报告、选项、窗口、帮助 |
| **标准工具栏** | 新建、打开、保存、打印、撤销、重做等常用操作 |
| **元件工具栏** | 按类别分类的元件库（电源、基本、二极管、晶体管、运放等） |
| **仿真工具栏** | 运行、暂停、停止、仿真类型选择 |
| **仪器工具栏** | 虚拟仪器仪表（示波器、信号源、万用表、波特图仪等） |
| **电路窗口** | 绘制和编辑电路图的工作区域 |
| **设计工具箱** | 层次化显示电路结构、页面、子电路 |
| **状态栏** | 显示当前操作提示与仿真状态 |

## 元件选择与放置

### 元件库分类

- **Sources** — 电源、信号源、接地、VCC/VDD、VEE/VSS
- **Basic** — 电阻、电容、电感、变压器、开关、继电器、连接器
- **Diodes** — 普通二极管、齐纳二极管、LED、整流桥、肖特基
- **Transistors** — BJT（NPN/PNP）、JFET、MOSFET
- **Analog** — 运算放大器（741、LM324 等）、比较器
- **TTL / CMOS** — 74 系列数字逻辑芯片、4000 系列
- **Misc** — 晶振、保险丝、光耦、电机、真空管
- **Indicators** — LED、蜂鸣器、七段数码管、虚拟灯泡
- **Mixed** — ADC/DAC、555 定时器、锁相环
- **RF** — 射频元件（电容、电感、晶体管、传输线）
- **Electro-Mechanical** — 继电器、马达、螺线管

### 放置操作

1. **Ctrl + W** — 打开元件选择对话框
2. 在搜索框输入元件名称（如 `LM741`, `2N3904`）
3. 双击元件或点击 **OK** 放置
4. 在电路窗口单击放置元件（移动鼠标可调整位置）
5. 放置后右击元件可旋转（**Ctrl + R**）、翻转、编辑属性

### 常用快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + W` | 打开元件选择 |
| `Ctrl + R` | 旋转选中元件（90°） |
| `Ctrl + Y` | 垂直翻转 |
| `Ctrl + X` | 水平翻转 |
| `Delete` | 删除选中元件 |
| `Ctrl + D` | 删除选中连线 |
| `Esc` | 取消当前操作 |
| `空格` | 放置已选中的元件 |

## 连线与电路构建

### 基本连线

- 鼠标悬停在元件引脚上，光标变为十字形时单击开始连线
- 移动鼠标到目标引脚再次单击完成连线
- 连线上双击可添加拐点（节点），拖拽拐点调整路径
- **自动连线**：直接从一个引脚拖到另一引脚，Multisim 自动选择最短路径
- **手动连线**：在空白处单击创建折线路径

### 节点与标签

- **节点**（Junction）：连线交汇处自动生成，编号为 1, 2, 3...
- **重命名节点**：双击节点编号，输入自定义名称（如 `Vout`、`Vin`）
- **总线**（Bus）：使用 **Place → Bus** 绘制多条信号线（适合数字电路）

### 网络标号

使用 **Place → Connectors → Global Connector** 或直接双击节点标号，适用于：

- 连接不同页面／层次电路中的同名节点
- 避免跨屏连线的杂乱
- 模块化设计中定义输入/输出端口

### 常用连线设置

- **导线颜色**：选中连线后右击 → **Segment Color**，便于区分不同信号
- **连线粗细**：Option → Global Preferences → Wiring → Wire Width
- **自动连线策略**：Option → Global Preferences → General → Autowire

## 虚拟仪器

Multisim 提供一系列虚拟仪器，无需实际硬件即可测量电路特性。

### 数字万用表（Multimeter）

- 测量：电压（DC/AC）、电流（DC/AC）、电阻、分贝
- 内阻、量程可设置（单击 **Set...**）
- 与实际万用表操作方式一致，注意正负表笔接法

### 函数信号发生器（Function Generator）

- 波形类型：正弦波、三角波、方波
- 参数：频率、占空比、幅值、偏移
- 输出：正极、负极、公共端
- 方波可调上升/下降时间

### 示波器（Oscilloscope）

- **双通道**（Channel A / B）：可同时观察两路信号
- **时基**（Timebase）：调节水平扫描速度（s/div）
- **通道设置**：垂直缩放（V/div）、耦合方式（AC/DC）、Y 轴偏移
- **触发**：触发源、边沿（上升/下降）、触发电平
- **测量**：游标（Cursor）读取精确值
- **扩展功能**：FFT 频谱分析（点击 **Reverse** 切换黑白背景便于打印）

### 四通道示波器（4-Channel Oscilloscope）

- 与双通道类似，支持 A/B/C/D 四个通道

### 波特图仪（Bode Plotter）

- 测量电路幅频特性和相频特性
- 模式选择：Magnitude（幅值）、Phase（相位）
- 坐标：对数/线性可调，起点/终点频率设置
- 适用于滤波器、放大器的频率响应分析

### 频谱分析仪（Spectrum Analyzer）

- 显示信号的频域分布
- 频率范围（Span）、中心频率（Center）、分辨率带宽（RBW）
- 可对数/线性显示

### 信号分析仪（Network Analyzer）

- 测 S 参数、驻波比、阻抗圆图
- 适用于 RF 电路仿真

### 逻辑分析仪（Logic Analyzer）

- 数字电路多通道波形显示
- 可设置时钟、触发条件
- 显示时序图和十六进制数据

### 逻辑转换器（Logic Converter）

- 真值表 ↔ 逻辑表达式 ↔ 逻辑电路 互相转换
- 简化布尔代数设计验证

### 瓦特表（Wattmeter）

- 测量功率（平均功率、功率因数）
- 电压线圈和电流线圈的接法

### 失真分析仪（Distortion Analyzer）

- 测量总谐波失真（THD）
- 可设置基频和谐波次数

### 伏安特性分析仪（IV Analyzer）

- 测量半导体器件（二极管、晶体管、MOSFET）的 I-V 特性曲线
- 适用于元件建模和参数提取

## 仿真类型

在 **Simulate → Analysis and Simulation** 中选择仿真类型。

### DC 工作点分析（DC Operating Point）

- 计算电路在直流稳态下的节点电压和支路电流
- 电容视为开路、电感视为短路
- 用于确定放大器的静态工作点（Q 点）
- **步骤**：Simulate → Analysis → DC Operating Point → 选择输出节点 → 运行

### 瞬态分析（Transient Analysis）

- 观察电路时域响应曲线
- 可设置仿真起始/结束时间
- 初始条件：零状态、用户自定义、从 DC 工作点开始
- **应用**：方波响应、脉冲响应、振荡起振
- 等效于示波器功能，但可输出更多数据点

### 交流分析（AC Sweep）

- 分析电路在不同频率下的增益和相位响应
- 扫频方式：线性、十倍频（Decade）、倍频（Octave）
- 起始/终止频率设置
- 输出：幅频曲线、相频曲线（与波特图仪等效）
- **应用**：滤波器频响、放大器带宽、谐振电路

### 直流扫描分析（DC Sweep）

- 改变某个电源电压或元件参数，观察电路的 DC 响应
- 可设置主扫描和次扫描（两个变量）
- **应用**：传输特性（Vin vs Vout）、MOSFET 转移特性

### 参数扫描（Parameter Sweep）

- 扫描元件参数（电阻值、电容值、晶体管模型参数等）
- 结合瞬态/AC 分析，观察参数变化对电路性能的影响
- **应用**：优化 RC 时间常数、调整滤波器截止频率

### 蒙特卡洛分析（Monte Carlo Analysis）

- 考虑元件容差，随机抽样统计电路性能分布
- 输出：均值、标准差、直方图、合格率
- **应用**：量产良率预测、最坏情况分析

### 傅里叶分析（Fourier Analysis）

- 对瞬态分析结果进行 FFT 变换
- 计算基频、谐波幅度和相位、THD（总谐波失真）
- **应用**：放大器失真分析、振荡器纯度

### 噪声分析（Noise Analysis）

- 计算电路中所有噪声源在输出端的总贡献
- 可输出噪声频谱密度曲线
- **应用**：低噪声放大器设计

### 其他分析

| 分析类型 | 用途 |
|----------|------|
| **Pole Zero** | 计算传输函数的极点和零点 |
| **Transfer Function** | 计算输入-输出传递函数、输入/输出阻抗 |
| **Sensitivity** | 分析元件参数变化对输出的敏感度 |
| **Worst Case** | 最坏情况分析（与蒙特卡洛互补） |
| **Trace Width** | PCB 走线宽度计算 |
| **Temperature Sweep** | 温度对电路性能的影响 |

## PCB 设计流程

Multisim 与 Ultiboard 配合完成 PCB 设计。

### 基本流程

1. **原理图设计**（Multisim）
   - 放置元件、连线
   - 添加网络标号
   - 分配 PCB 封装（Footprint）

2. **设计规则检查**（DRC）
   - Tools → Database → Footprint 验证封装分配
   - 确保所有元件有正确封装

3. **导入 Ultiboard**
   - Transfer → Transfer to Ultiboard
   - 或导出 Netlist（Transfer → Export Netlist）

4. **布局布线**（Ultiboard）
   - 板框定义（Board Outline）
   - 元件布局
   - 自动/手动布线
   - 覆铜（Copper Pour）
   - 设计规则（线宽、间距、过孔）

5. **输出 Gerber 文件**
   - File → Export → Gerber
   - 用于 PCB 制板

### PCB 封装分配

- 选中元件 → 右击 → **Edit Symbol/Footprint**
- 在 **Footprint** 选项卡中选择封装
- 常用封装：RES-0805、DIP-8、SOP-14、TO-92

## 常见电路示例

### 1. 运算放大器反相放大

```
Vin ── R1(10k) ──┬── V⁻(LM741)
                 │
                Rf(100k)
                  │
                 Vout
```

- 增益：Av = −Rf / R1 = −10
- 仿真：DC 传输特性（Vin = −1V ~ +1V）

### 2. 555 定时器 — 占空比可调

- 外接 RA、RB、C
- 频率 f = 1.44 / ((RA + 2RB) × C)
- 观察 OUT 引脚方波输出（瞬态分析 + 示波器）

### 3. RC 低通滤波器

- 截止频率 fc = 1 / (2πRC)
- 交流扫描验证 −3dB 点
- 对比理论计算值

### 4. 晶体管共射放大电路

- 确定 Q 点（DC Operating Point）
- Vin 输入小信号正弦波，观察 Vout 放大波形
- 交流扫描测带宽

### 实用技巧

- **符号标准**：Options → Global Preferences → Schematic → Symbol Set，可选 ANSI（美标）或 DIN（欧标/国标），国内教学常用 DIN
- **探针工具**（Probe）：仿真工具栏上的探针图标，拖拽到连线上可实时显示电压、电流、频率
- **虚拟仿真错误**：检查接地！SPICE 要求电路必须有参考地，否则仿真报错
- **收敛问题**：Simulate → Interactive Simulation Settings → 减小最大时间步长（Max Time Step）或改用 Gear 积分法
- **元件搜索**：元件对话框的 Search 框中支持通配符，如 `74*` 列出所有 74 系列芯片
- **复制/粘贴电路模块**：选中电路区域 → `Ctrl + C` → `Ctrl + V`，贴到同一页面或不同页面
- **子电路**（Subcircuit）：将重复电路层级化，Place → Subcircuit，方便大型电路管理和复用
- **仿真数据导出**：仿真完成后，Grafer 窗口中 File → Export → Export Data to Excel
- **元件数据库管理**：Tools → Database → Database Manager，可新增用户元件或编辑现有元件
- **表格视图**：View → Spreadsheet View，批量查看和编辑元件属性（值、封装、容差）

## 注意事项

- **务必接地**：SPICE 仿真必须至少有一个 0V 参考地
- **电源命名规范**：VCC（正电源）、VEE（负电源）、DGND（数字地）、AGND（模拟地）
- **仿真速度优化**：去掉不需要的探针，减少波形数据保存点数
- **收敛失败**：检查是否存在浮空节点、悬空引脚、高阻抗回路
- **教学版本限制**：Education 版元件数量和节点数有限制，复杂电路需用 Full 版
- **文件兼容性**：不同版本之间保存格式可能不兼容，建议保存为 `.ms14` 格式
