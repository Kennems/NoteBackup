# 图片压缩

这里压缩的是 PicGo + Git 搭建的图床

### **一、图形界面工具（适合新手）**
#### 1. **XnConvert（跨平台：Windows/macOS/Linux）**
  - **步骤**：
    1. 下载安装：[XnConvert官网](https://www.xnview.com/en/xnconvert/)
    2. 打开工具，点击 `Input` 添加需要压缩的图片文件夹。
    3. 在 `Actions` 选项卡添加压缩操作：
       - 点击 `Add action` → 选择 `Image` → `Resize`（可选调整尺寸）或 `Compression` → 调整压缩质量（例如 JPEG 质量设为 70%）。
    4. 在 `Output` 选项卡设置输出路径为原文件夹，勾选 `Overwrite existing files`（直接覆盖原文件，文件名不变）。
    5. 点击 `Convert` 开始批量压缩。

#### 2. **Caesium（Windows/macOS/Linux）**
  - **特点**：专门用于图片压缩，支持保留元数据。
  - **步骤**：
    1. 下载：[Caesium官网](https://saerasoft.com/caesium/)
    2. 添加文件夹 → 设置压缩质量 → 输出路径选择原文件夹并启用覆盖。

#### 3. **ImageOptim（macOS）**
  - **特点**：拖拽即可压缩，自动覆盖原文件。
  - 下载：[ImageOptim官网](https://imageoptim.com/mac)

### **二、命令行工具（适合技术用户）**
#### 1. **ImageMagick（跨平台）**
  - **安装**：
    ```bash
    # macOS
    brew install imagemagick
    
    # Linux
    sudo apt-get install imagemagick
    
    # Windows：从官网下载安装包
    ```
  - **批量压缩命令**：
    ```bash
    mogrify -format jpg -path 原文件夹路径 -quality 70% *.jpg
    ```
    - `-quality 70%`: 调整压缩质量（数值越低压缩率越高）。
    - **注意**：此命令会直接覆盖原文件，建议先备份！

#### 2. **FFmpeg（视频工具，但支持图片压缩）**
  ```bash
  for file in *.jpg; do ffmpeg -i "$file" -compression_level 5 "output/$file"; done
  ```

### **三、Python脚本（灵活自定义）**
可以用 Python + Pillow 库实现：
```python
from PIL import Image
import os

input_folder = "你的图片文件夹路径"
quality = 70  # 压缩质量（1-100）

for filename in os.listdir(input_folder):
    if filename.lower().endswith(('.png', '.jpg', '.jpeg')):
        filepath = os.path.join(input_folder, filename)
        img = Image.open(filepath)
        img.save(filepath, optimize=True, quality=quality)
```
- **运行**：保存为 `compress.py`，安装 Pillow 库后执行：
  
  ```bash
  pip install pillow
  python compress.py
  ```

---

### **四、注意事项**
1. **备份原图**：压缩可能导致画质损失，建议先备份文件夹。
2. **格式兼容性**：确保工具支持你的图片格式（如 JPEG、PNG、WebP）。
3. **覆盖文件**：部分工具默认添加后缀（如 `_compressed`），需在设置中关闭。

根据你的需求选择最适合的方案！
