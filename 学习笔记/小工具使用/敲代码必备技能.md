# 敲代码必备技能

## 一、Linux

### 1.1 常用基本命令

```bash
# 文件目录操作
ls                    # 列出当前目录文件
ls -la                # 列出所有文件（含隐藏文件）详细信息
pwd                   # 显示当前路径
cd ~                  # 进入 home 目录
cd -                  # 返回上一个目录
mkdir -p a/b/c        # 递归创建目录
rm -rf dir            # 递归强制删除目录
cp -r src dst         # 递归复制目录
mv old new            # 移动 / 重命名

# 查看文件内容
cat file              # 显示全部内容
less file             # 分页查看（q 退出，/ 搜索）
head -n 20 file       # 查看前 20 行
tail -f file          # 实时跟踪文件末尾（日志）
nl file               # 显示行号输出
```

### 1.2 文件系统结构

| 目录 | 用途 |
|------|------|
| `/` | 根目录 |
| `/etc` | 系统配置文件 |
| `/var` | 可变数据（日志、缓存） |
| `/tmp` | 临时文件（重启清空） |
| `/home` | 用户目录 |
| `/usr` | 用户程序与库文件 |
| `/opt` | 第三方软件 |

### 1.3 权限管理

```bash
chmod 755 file         # rwxr-xr-x  属主读写执行，组和其他读执行
chmod u+x file         # 给属主加执行权限
chown user:group file  # 修改属主和属组
umask 022              # 设置默认权限掩码
```

权限数字：`r=4, w=2, x=1`，755 = rwx（7）r-x（5）r-x（5）。

### 1.4 进程管理

```bash
ps aux                 # 查看所有进程
ps -ef                 # 全格式进程列表
top                    # 实时进程监控（按 CPU / 内存排序）
htop                   # 增强版 top（需安装）
kill -9 PID            # 强制杀死进程
kill -15 PID           # 优雅终止
pkill name             # 按名称杀进程
nohup cmd &            # 后台运行并忽略挂断
jobs                   # 查看后台任务
fg %1                  # 将任务 1 调到前台
```

### 1.5 网络相关

```bash
ping host              # 测试连通性
curl -v url            # HTTP 请求
wget url               # 下载文件
netstat -tlnp          # 查看端口监听
ss -tlnp               # 新版 netstat
ifconfig               # 查看网络接口（或 ip addr）
ssh user@host          # SSH 远程登录
scp file user@host:path   # 远程拷贝
```

## 二、Vim

### 2.1 三种基本模式

| 模式 | 说明 | 如何进入 |
|------|------|---------|
| Normal（普通模式） | 导航、复制、删除、粘贴 | 默认，按 `Esc` |
| Insert（插入模式） | 编辑文本 | `i`、`a`、`o`、`I`、`A`、`O` |
| Visual（可视模式） | 选择文本 | `v`（字符）、`V`（行）、`Ctrl+v`（块） |

### 2.2 文件操作

```vim
:e file      " 打开文件
:w           " 保存
:q           " 退出
:wq          " 保存并退出
:q!          " 强制退出不保存
:x           " 保存并退出（同 wq）
:e!          " 重新加载放弃修改
```

### 2.3 光标移动

```vim
h j k l      " 左 下 上 右
w / b        " 按词前进 / 后退
0 / $        " 行首 / 行尾
gg / G       " 文件首 / 文件尾
123G         " 跳转到第 123 行
Ctrl+f / b   " 下翻一页 / 上翻一页
%            " 匹配括号跳转
```

### 2.4 编辑操作

```vim
i / a        " 光标前插入 / 后插入
I / A        " 行首插入 / 行尾追加
o / O        " 下方新行 / 上方新行插入
x            " 删除光标处字符
dd           " 删除当前行
yy           " 复制当前行
p / P        " 粘贴在光标后 / 前
u / Ctrl+r   " 撤销 / 重做
.            " 重复上次操作
```

### 2.5 查找替换

```vim
/pattern     " 向下搜索
?pattern     " 向上搜索
n / N        " 下一个 / 上一个匹配
:%s/old/new/g    " 全局替换
:%s/old/new/gc   " 全局替换（逐个确认）
:5,10s/old/new/g " 第 5~10 行替换
```

### 2.6 窗口与多文件

```vim
:sp file     " 水平分屏
:vsp file    " 垂直分屏
Ctrl+w w     " 切换窗口
Ctrl+w q     " 关闭当前窗口
:tabnew file " 新标签页打开
gt / gT      " 下一个 / 上一个标签
```

## 三、Git

### 3.1 配置与初始化

```bash
git config --global user.name "Your Name"
git config --global user.email "your@email.com"
git config --global core.editor vim
git init                 # 初始化本地仓库
git clone url            # 克隆远程仓库
```

### 3.2 基本操作

```bash
git status               # 查看工作区状态
git add file             # 暂存文件
git add .                # 暂存所有变更
git commit -m "message"  # 提交
git commit -am "msg"     # 暂存并提交（跳过 add，仅跟踪过的文件）
git log --oneline --graph   # 简洁图形化日志
git diff                 # 查看工作区与暂存区差异
git diff --staged        # 查看暂存区与 HEAD 差异
```

### 3.3 远程仓库

```bash
git remote add origin url    # 添加远程仓库
git push origin main         # 推送到远程
git push -u origin main      # 推送到远程并建立跟踪
git pull                     # 拉取并合并（fetch + merge）
git fetch origin             # 只拉取不合并
git remote -v                # 查看远程仓库
```

### 3.4 分支管理

```bash
git branch                   # 查看本地分支
git branch name              # 创建分支
git switch name              # 切换分支（新版）
git checkout name            # 切换分支（旧版）
git switch -c name           # 创建并切换
git merge name               # 将 name 分支合并到当前分支
git branch -d name           # 删除本地分支
git push origin --delete name    # 删除远程分支
```

### 3.5 合并与变基

```bash
# merge — 保留分支历史
git checkout main
git merge feature

# rebase — 线性历史
git checkout feature
git rebase main

# 交互式 rebase — 整理提交历史
git rebase -i HEAD~3
```

交互式 rebase 常用操作：`pick`、`reword`（改信息）、`squash`（合并到上一个）、`drop`（删除）。

### 3.6 撤销与回退

```bash
git restore file            # 丢弃工作区修改
git restore --staged file   # 取消暂存
git reset --soft HEAD~1     # 回退一次提交，保留修改
git reset --hard HEAD~1     # 回退一次提交，丢弃修改
git revert HEAD             # 撤销某次提交（生成新提交）
git stash                   # 暂存当前修改
git stash pop               # 恢复暂存
git stash list              # 查看暂存列表
```

## 四、Docker

### 4.1 镜像操作

```bash
docker images               # 列出本地镜像
docker pull nginx:latest    # 拉取镜像
docker search nginx         # 搜索镜像
docker rmi nginx            # 删除镜像
docker build -t myapp .     # 从 Dockerfile 构建镜像
docker tag myapp myapp:v1   # 给镜像打标签
docker push myapp:v1        # 推送镜像到仓库
```

### 4.2 容器操作

```bash
docker run nginx                # 运行容器
docker run -d --name web -p 80:80 nginx   # 后台运行，端口映射
docker run -it ubuntu bash       # 交互式运行
docker ps                       # 查看运行中容器
docker ps -a                    # 查看所有容器
docker stop container           # 停止容器
docker start container          # 启动已停止容器
docker restart container        # 重启容器
docker rm container             # 删除容器
docker rm -f container          # 强制删除
docker logs -f container        # 查看日志
docker exec -it container bash  # 进入容器内
docker cp file container:/path  # 复制文件到容器
```

### 4.3 Dockerfile 示例

```dockerfile
FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
EXPOSE 3000
CMD ["node", "server.js"]
```

### 4.4 docker-compose

```yaml
version: '3'
services:
  web:
    build: .
    ports:
      - "3000:3000"
    depends_on:
      - db
  db:
    image: postgres:15
    environment:
      POSTGRES_PASSWORD: secret
```

```bash
docker-compose up -d        # 启动所有服务
docker-compose down         # 停止并删除容器
docker-compose logs -f      # 查看日志
docker-compose ps           # 查看服务状态
docker-compose exec web sh  # 进入服务容器
```

### 4.5 数据卷与网络

```bash
docker volume create data    # 创建数据卷
docker volume ls             # 列出数据卷
docker network create net    # 创建网络
docker network ls            # 列出网络
docker run -v data:/data ... # 挂载数据卷
docker run --network net ... # 指定网络
```

## 五、Shell 脚本基础

### 5.1 变量与参数

```bash
#!/bin/bash
name="world"
echo "Hello, $name"
echo "脚本名: $0"
echo "参数1: $1"
echo "参数个数: $#"
echo "所有参数: $@"
echo "退出码: $?"
```

### 5.2 条件判断

```bash
if [ -f "$file" ]; then
  echo "文件存在"
elif [ -d "$dir" ]; then
  echo "目录存在"
else
  echo "都不存在"
fi

# 常用判断
[ -f file ]     # 是否为文件
[ -d dir ]      # 是否为目录
[ -z str ]      # 字符串是否为空
[ "$a" = "$b" ] # 字符串相等
[ "$a" -eq 1 ]  # 数字相等（-ne, -gt, -lt, -ge, -le）
```

### 5.3 循环

```bash
# for 循环
for f in *.txt; do
  echo "处理 $f"
done

for i in {1..5}; do
  echo "第 $i 次"
done

# while 循环
while read line; do
  echo "$line"
done < input.txt

# 无限循环
while true; do
  echo "running..."
  sleep 1
done
```

### 5.4 函数

```bash
function log() {
  local msg="$1"
  echo "[$(date '+%Y-%m-%d %H:%M:%S')] $msg"
}

log "脚本开始执行"
```

### 5.5 实用技巧

```bash
# 管道与重定向
cmd1 | cmd2            # 管道
cmd > file             # 输出重定向（覆盖）
cmd >> file            # 输出重定向（追加）
cmd 2>&1               # 错误输出合并到标准输出
cmd &> file            # 所有输出到文件（bash 4+）

# 命令替换
now=$(date +%s)
now=`date +%s`         # 旧式写法

# 默认值
echo "${name:-default}"   # 变量未定义时用默认值
echo "${name:=default}"   # 变量未定义时赋值并输出
```

## 六、调试技巧

### 6.1 代码调试

```bash
# Shell 脚本调试
bash -x script.sh            # 逐行跟踪执行
set -x                       # 在脚本内开启调试
set +x                       # 关闭调试
set -e                       # 遇到错误立即退出
set -u                       # 使用未定义变量时报错
trap 'echo "错误行: $LINENO"' ERR  # 捕获错误

# Python 调试
python -m pdb script.py
# 常用 pdb 命令：n(下⼀步), s(进⼊函数), c(继续), p(打印), l(查看代码)
breakpoint()                 # Python 3.7+ 内置断点

# Node.js 调试
node inspect app.js
# 在代码中加 debugger 语句
```

### 6.2 日志分析

```bash
tail -f app.log              # 实时跟踪日志
tail -n 100 app.log | grep ERROR   # 查看最后 100 行中的错误
journalctl -u nginx -f       # systemd 日志
dmesg | tail                 # 内核日志
```

### 6.3 性能分析

```bash
time command                 # 测量命令执行时间
strace -p PID               # 跟踪系统调用
lsof -i :port               # 查看端口占用
du -sh dir                  # 查看目录大小
df -h                       # 查看磁盘空间
free -h                     # 查看内存使用
```

## 七、搜索技能

### 7.1 grep — 文本搜索

```bash
grep "pattern" file          # 基本搜索
grep -i "pattern" file       # 忽略大小写
grep -r "pattern" dir/       # 递归搜索目录
grep -n "pattern" file       # 显示行号
grep -C 3 "pattern" file     # 显示前后 3 行上下文
grep -v "pattern" file       # 反向匹配（不含 pattern 的行）
grep -l "pattern" *.py       # 只显示匹配的文件名
grep -E "err|warn" log       # 扩展正则（或）
grep -o "pattern" file       # 只输出匹配的部分
rg "pattern"                 # ripgrep（更快的 grep）
```

正则示例：`^Hello`、`world$`、`colou?r`、`\d{3}-\d{4}`。

### 7.2 find — 文件查找

```bash
find . -name "*.py"                       # 按名称查找
find . -iname "*.py"                      # 忽略大小写
find . -type f -size +10M                # 大于 10MB 的文件
find . -type d -name "test"              # 查找目录
find . -mtime -1                         # 最近 1 天修改的文件
find . -perm 755                         # 按权限查找
find . -name "*.tmp" -delete             # 找到并删除
find . -name "*.log" -exec rm {} \;      # 对每个结果执行命令
```

### 7.3 其他搜索工具

```bash
# 命令历史搜索
Ctrl+r                     # 反向搜索历史命令
history | grep "docker"    # 查找历史命令

# 代码搜索
ag "pattern"               # silver searcher（极快）
rg "pattern"               # ripgrep（Rust 实现，推荐）

# 文件内容快速查看
tree                       # 目录树结构
tree -L 2                  # 限制深度 2 层
which command              # 定位可执行文件路径
type command               # 查看命令类型（内建 / 别名 / 外部）
```

### 7.4 组合使用

```bash
# 查找日志中的错误，按出现次数排序
grep -o "ERROR.*" app.log | sort | uniq -c | sort -rn

# 查找所有包含 TODO 的代码文件
grep -rn "TODO" --include="*.{js,py,go,rs}" .

# 查找最近修改的大文件
find . -type f -size +50M -mtime -7

# 统计代码行数
find . -name "*.go" -exec wc -l {} + | tail -1
```

## 八、效率工具组合

### 8.1 别名与配置

```bash
# 添加到 ~/.bashrc 或 ~/.zshrc
alias ll='ls -lah'
alias gs='git status'
alias gc='git commit'
alias gp='git push'
alias gpl='git pull'
alias gd='git diff'
alias dc='docker compose'

# 快速进入常用目录
alias notes='cd ~/Notes && ls -la'
```

### 8.2 Tmux — 终端复用

```bash
tmux new -s session      # 新建会话
tmux a -t session        # 接入会话
tmux ls                  # 列出会话

# 快捷键（前缀默认 Ctrl+b）
Ctrl+b %                 # 垂直分屏
Ctrl+b "                 # 水平分屏
Ctrl+b 方向键            # 切换窗格
Ctrl+b d                 # 分离会话
Ctrl+b [                 # 进入滚动模式
```

### 8.3 日常高效技巧

```bash
# 快速创建备份
cp file{,.bak}

# 用上一个参数
!!                      # 重复上一条命令
!$                      # 上个命令的最后一个参数
mkdir foo && cd $_       # 创建并进入

# 在当前目录创建并切入
mkcd() { mkdir -p "$1" && cd "$1"; }

# 重试命令直到成功
until cmd; do echo "retrying..."; sleep 1; done
```
