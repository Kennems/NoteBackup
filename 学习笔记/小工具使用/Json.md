# Json 

文本数据格式，树形格式

# 支持类型

- 常规类型

  1. 字符串
  2. 数字
  3. 布尔值
  4. null

- 允许内嵌类型

  1. 对象

     ```json
     如:{"key1":"value1","key2":"value2"}
     ```

  2. 数组

```json
      ["value1", "value2", "value3"]
      ```
