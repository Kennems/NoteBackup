# 语言识别

## 概述

语音识别（Speech Recognition）是将语音信号转换为文本的技术。语言识别（Language Identification）则是判断一段语音所属的语言类别。MATLAB 通过 Audio Toolbox 和 Signal Processing Toolbox 提供了完整的语音处理与识别工具链。

---

## 一、音频信号处理基础

### 1.1 音频信号的表示

在 MATLAB 中，音频信号通常以离散时间序列表示：

```matlab
[y, fs] = audioread('speech.wav');
% y: 采样点序列 (N×1 或 N×C, C为通道数)
% fs: 采样率 (Hz)
```

- **采样率**：语音信号常用 8kHz（电话）、16kHz（宽带）或 44.1kHz（CD 质量）
- **量化位数**：通常为 16 位 PCM
- **通道数**：单声道（mono）或双声道（stereo）

### 1.2 预加重（Pre-emphasis）

预加重用于提升高频分量，补偿语音信号中高频能量衰减：

```matlab
preemph = [1, -0.97];  % 预加重系数
y_pre = filter(preemph, 1, y);
```

### 1.3 分帧与加窗

语音信号是短时平稳的，通常分成 20-40ms 的帧，帧移为 10ms：

```matlab
frameLen = 0.025 * fs;       % 25ms 帧长
frameShift = 0.010 * fs;     % 10ms 帧移
numFrames = floor((length(y) - frameLen) / frameShift) + 1;
frames = zeros(frameLen, numFrames);
for i = 1:numFrames
    idx = (i-1)*frameShift + 1;
    frames(:,i) = y(idx:idx+frameLen-1) .* hamming(frameLen);
end
```

常用窗函数：汉明窗（Hamming）、汉宁窗（Hanning）、布莱克曼窗（Blackman）。

## 二、特征提取

### 2.1 短时傅里叶变换（STFT）与语谱图

STFT 是语音分析的基础，语谱图（Spectrogram）是其可视化表示：

```matlab
[S, F, T] = stft(y, fs, 'Window', hamming(512), 'OverlapLength', 384, 'FFTLength', 512);
spectrogram(y, hamming(512), 384, 512, fs, 'yaxis');
```

- **纵轴**：频率（Hz）
- **横轴**：时间（s）
- **颜色深浅**：能量强度（dB）

### 2.2 MFCC（梅尔频率倒谱系数）

MFCC 是语音识别中最常用的特征，模拟人耳听觉特性：

```matlab
% 使用 Audio Toolbox 提取 MFCC
afe = audioFeatureExtractor('SampleRate', fs, ...
    'mfcc', true, 'mfccDelta', true, 'mfccDeltaDelta', true, ...
    'Window', hamming(frameLen, 'periodic'), 'OverlapLength', frameLen - frameShift);
features = extract(afe, y);
```

MFCC 提取步骤：
1. 分帧加窗
2. FFT 求功率谱
3. Mel 滤波器组（三角滤波器，等距分布在 Mel 刻度上）
4. 取对数
5. DCT 变换，取前 13 维系数

Mel 频率与线性频率的转换：

$$Mel(f) = 2595 \cdot \log_{10}(1 + \frac{f}{700})$$

### 2.3 其他常用特征

| 特征 | 说明 |
|------|------|
| **LPCC** | 线性预测倒谱系数，基于声道模型 |
| **FBANK** | 滤波器组能量（MFCC 去掉 DCT 步骤） |
| **PLP** | 感知线性预测，结合听觉模型 |
| **Chroma** | 色度特征，用于音乐和韵律分析 |
| **ZCR** | 过零率，区分清音/浊音 |
| **能量/短时能量** | 语音活动检测（VAD）基础 |

### 2.4 特征后处理

- **均值归一化**：减去全局均值，减少信道影响
- **CMVN**（倒谱均值方差归一化）：每个特征维度归零化
- **特征拼接**：前后帧拼接获得时序上下文

```matlab
% CMVN 示例
features = (features - mean(features)) ./ std(features);
```

## 三、语音识别方法

### 3.1 动态时间规整（DTW）

DTW 用于测量两个长度不同的语音序列的相似度，适合小词汇量孤立词识别：

```matlab
dist = dtw(features1, features2);
```

- 优点：无需训练，模板匹配
- 缺点：计算量大，难以扩展到大词汇量

### 3.2 隐马尔可夫模型（HMM）

HMM 是传统语音识别的核心模型，每个音素/单词对应一个 HMM：

```matlab
% 创建 HMM 模型
hmmModel = hmmtrain(seq, trans_guess, emit_guess);
% 使用 Statistics and Machine Learning Toolbox
```

HMM 三大问题：
1. **评估**：前向-后向算法
2. **解码**：Viterbi 算法（找到最优状态序列）
3. **训练**：Baum-Welch 算法（EM 算法）

### 3.3 高斯混合模型（GMM）

GMM 拟合语音特征的概率分布，每个语音单元用多个高斯分布加权表示：

```matlab
gmm = fitgmdist(features, 32, 'RegularizationValue', 0.01);
```

GMM-HMM 混合模型曾是主流框架：HMM 建模时序结构，GMM 建模观测概率。

### 3.4 深度学习模型（DNN/RNN/Transformer）

#### DNN-HMM 混合系统

DNN 替代 GMM 计算 HMM 的观测概率，识别率显著提升：

```matlab
layers = [
    featureInputLayer(39, 'Normalization', 'zscore')
    fullyConnectedLayer(512)
    reluLayer
    dropoutLayer(0.2)
    fullyConnectedLayer(256)
    reluLayer
    dropoutLayer(0.2)
    fullyConnectedLayer(numPhones)
    softmaxLayer
    classificationLayer];
options = trainingOptions('adam', 'MaxEpochs', 50, 'MiniBatchSize', 128);
net = trainNetwork(trainFeatures, trainLabels, layers, options);
```

#### 端到端模型

- **Listen, Attend and Spell (LAS)**：基于注意力机制的 Encoder-Decoder
- **Connectionist Temporal Classification (CTC)**：无需对齐的序列到序列映射
- **RNN-T（Transducer）**：流式识别模型

```matlab
% 使用 Deep Learning Toolbox 构建 LSTM 声学模型
layers = [
    sequenceInputLayer(39)
    bilstmLayer(256, 'OutputMode', 'sequence')
    dropoutLayer(0.3)
    bilstmLayer(256, 'OutputMode', 'sequence')
    fullyConnectedLayer(numClasses)
    softmaxLayer
    classificationLayer];
```

#### Wav2Vec / HuBERT（自监督学习）

近年主流方法，在大规模无标注数据上预训练，在下游任务微调：

```matlab
% 通过调用 Python 模型接口
net = importNetworkFromPyTorch('wav2vec_model.pth');
```

### 3.5 语言模型融合

语音识别中语言模型（LM）用于约束解码路径：

- **N-gram 语言模型**：统计词序列概率
- **神经网络语言模型**：RNNLM / Transformer LM
- **WFST 解码**：加权有限状态转换器，整合声学模型、词典、语言模型

```matlab
% 使用 Text Analytics Toolbox 构建简单 bi-gram LM
bag = bagOfNgrams(tokenizedText);
tbl = topkngrams(bag, 10);
```

## 四、语言识别技术

### 4.1 任务定义

语言识别（LID, Language Identification）区分语音所属的语言种类（如中文 vs 英文 vs 日文）。

### 4.2 传统方法

- **基于音素识别器**：先用通用音素识别器解码，再用语言模型打分
- **基于 i-vector**：将整个语音段映射为固定维度的 i-vector，再用分类器（SVM/PLDA）判断语言

```matlab
% i-vector 提取示意
ubm = fitgmdist(allFeatures, 1024, 'RegularizationValue', 0.01);
% 计算 Baum-Welch 统计量
% 使用 Total Variability 矩阵投影得到 i-vector
```

### 4.3 深度学习方法

#### 基于 x-vector

x-vector 是当前 LID 的主流方法，使用 TDNN（时延神经网络）：

```matlab
layers = [
    sequenceInputLayer(40)
    tdnnLayer('conv1', 512, [5,1], [1,1])
    tdnnLayer('conv2', 512, [3,1], [1,1])
    tdnnLayer('conv3', 512, [3,1], [1,1])
    tdnnLayer('conv4', 128, [1,1], [1,1])
    statisticsPoolingLayer          % 全局均值+标准差池化
    fullyConnectedLayer(512)
    fullyConnectedLayer(numLanguages)
    softmaxLayer
    classificationLayer];
```

#### 基于 Transformer / CNN

- **ResNet + 语谱图**：将语谱图视为图像，用 CNN 分类
- **Self-Attention 池化**：替代统计池化，自适应加权帧级特征

### 4.4 常用的语言识别数据集

| 数据集 | 语言数 | 说明 |
|--------|--------|------|
| **NIST LRE** | 数十种 | 官方评测数据集 |
| **VoxLingua107** | 107 | YouTube 收集 |
| **Common Language** | 50+ | 开源语言识别数据集 |

### 5.4 完整的语音识别流程

```matlab
% 1. 数据准备
ads = audioDatastore('speech_data/', 'IncludeSubfolders', true, ...
    'LabelSource', 'foldernames');
[adsTrain, adsTest] = splitEachLabel(ads, 0.8);

% 2. 特征提取
afe = audioFeatureExtractor('SampleRate', fs, ...
    'mfcc', true, 'mfccDelta', true, 'Window', hamming(400), ...
    'OverlapLength', 300);
featuresTrain = cellfun(@(x) extract(afe, x), adsTrain.readall(), ...
    'UniformOutput', false);

% 3. 训练分类器（LSTM）
layers = [
    sequenceInputLayer(39)
    lstmLayer(128, 'OutputMode', 'last')
    fullyConnectedLayer(10)
    softmaxLayer
    classificationLayer];
options = trainingOptions('adam', 'MaxEpochs', 30, 'MiniBatchSize', 32, ...
    'Plots', 'training-progress');
net = trainNetwork(featuresTrain, adsTrain.Labels, layers, options);

% 4. 测试
featuresTest = cellfun(@(x) extract(afe, x), adsTest.readall(), ...
    'UniformOutput', false);
pred = classify(net, featuresTest);
acc = mean(pred == adsTest.Labels);
fprintf('测试准确率: %.2f%%\n', acc * 100);
```

### 5.5 实时录音识别

```matlab
% 使用 Audio Device Reader 进行实时录音
deviceReader = audioDeviceReader('SampleRate', fs, 'SamplesPerFrame', 512);
while true
    audio = deviceReader();
    features = extract(afe, audio);
    label = classify(net, features);
    disp(['识别结果: ', char(label)]);
end
```

## 七、应用与局限性

### 7.1 主要应用

- **智能语音助手**：Siri、Google Assistant、Alexa
- **自动语音转录**：会议记录、字幕生成
- **语言识别**：多语言客服路由、语种自动切换
- **说话人识别**：声纹认证、安全验证
- **情感识别**：基于韵律特征的情绪检测

### 7.2 当前局限与挑战

| 挑战 | 说明 |
|------|------|
| **噪声鲁棒性** | 真实场景中背景噪声严重影响识别率 |
| **远场识别** | 距离远导致信噪比低、混响严重 |
| **方言/口音** | 同一语言的不同变体差异大 |
| **语码混合** | 说话中混合多种语言（如中英夹杂） |
| **数据稀缺** | 低资源语言训练数据不足 |
| **实时性要求** | 端侧设备算力有限，延迟要求高 |

### 7.3 改进方向

- 自监督预训练（WavLM, HuBERT, Wav2Vec 2.0）
- 多模态融合（音视频联合识别）
- 端到端联合训练（声学+语言模型联合优化）
- 联邦学习（隐私保护下的模型训练）
- 大语言模型驱动的语音理解（Speech-LLM）

## 八、总结

语音识别技术已经历了从 DTW → GMM-HMM → DNN-HMM → 端到端模型的发展历程。MATLAB 提供了完整的工具链支持上述各阶段方法的实现，适合快速原型验证和教学实验。但在大规模工业级部署中，主流方案仍以 Kaldi、Espnet、WeNet、Whisper 等开源框架为主。理解 MATLAB 实现有助于深入理解语音识别的基本原理，为后续迁移到更复杂的框架奠定基础。
