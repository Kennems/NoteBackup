# 数据结构与算法

## 概览

数据结构是计算机存储、组织数据的方式，算法是解决问题的步骤和方法。选择合适的数据结构能大幅提升算法效率。本页作为快速参考速查表。

## 常见数据结构

### 数组（Array）
- **访问** O(1) | **搜索** O(n) | **插入/删除** O(n)
- 按索引随机访问最快，但中间插入/删除需要搬移元素
- 动态数组（如 ArrayList）在末尾追加均摊 O(1)
- **适用场景**：需要快速按下标访问、数据量固定或仅在末尾增删

### 链表（Linked List）
- **访问/搜索** O(n) | **插入/删除（已知位置）** O(1)
- 无需连续内存，插入删除快，但不支持随机访问
- 变体：单向链表、双向链表、循环链表
- **适用场景**：频繁插入删除、无需随机访问

### 栈（Stack）
- **入栈/出栈** O(1) | **搜索** O(n)
- 后进先出（LIFO），典型操作：push、pop、peek
- **适用场景**：函数调用栈、括号匹配、浏览器后退、单调栈问题

### 队列（Queue）
- **入队/出队** O(1) | **搜索** O(n)
- 先进先出（FIFO），变体有双端队列（Deque）、优先队列（Heap 实现）
- **适用场景**：BFS、任务调度、滑动窗口

### 哈希表（Hash Table / HashMap）
- **查找/插入/删除** 均摊 O(1)，最坏 O(n)
- 通过哈希函数映射键到位置，需处理冲突（链地址法或开放寻址）
- 不保证有序，不支持范围查询
- **适用场景**：快速键值查找、去重、计数

### 树（Tree）
- **二叉搜索树（BST）**：查找/插入/删除 O(log n) 平均，最坏 O(n)（退化为链表）
- **平衡树（AVL / 红黑树）**：全部操作保证 O(log n)
- **堆（Heap）**：插入/删除 O(log n)，取最值 O(1)
- **适用场景**：层次化数据、快速查找/排序（BST）、优先队列（堆）、表达式解析

### 图（Graph）
- 存储方式：邻接表（O(V+E) 空间，适合稀疏图）、邻接矩阵（O(V²) 空间，适合稠密图）
- **BFS**（广度优先）O(V+E)，使用队列，求最短路径
- **DFS**（深度优先）O(V+E)，使用栈或递归，求连通性/拓扑排序
- **Dijkstra** 最短路径 O(E + V log V)（优先队列优化）
- **适用场景**：社交网络、路径规划、依赖分析、推荐系统

## 时间复杂度速查表

| 数据结构 | 访问 | 查找 | 插入 | 删除 |
|----------|------|------|------|------|
| 数组 | O(1) | O(n) | O(n) | O(n) |
| 链表 | O(n) | O(n) | O(1)* | O(1)* |
| 栈/队列 | O(n) | O(n) | O(1) | O(1) |
| 哈希表 | O(1)* | O(1)* | O(1)* | O(1)* |
| 平衡 BST | O(log n) | O(log n) | O(log n) | O(log n) |
| 堆 | — | O(n) | O(log n) | O(log n) |

> * 标记为均摊或平均情况，最坏情况可能不同（如哈希表因冲突最坏 O(n)）

## 选型决策

| 需求 | 推荐结构 |
|------|----------|
| 快速按索引访问 | 数组 |
| 频繁在任意位置插入删除 | 链表 |
| 按键快速查找 | 哈希表 |
| 保持有序 + 快速查找 | 平衡 BST（TreeMap） |
| 始终获取最大/最小值 | 堆（优先队列） |
| 表示关系/网络/路径 | 图 |

## 常用排序算法复杂度

| 算法 | 平均 | 最坏 | 空间 | 是否稳定 |
|------|------|------|------|----------|
| 快速排序 | O(n log n) | O(n²) | O(log n) | 否 |
| 归并排序 | O(n log n) | O(n log n) | O(n) | 是 |
| 堆排序 | O(n log n) | O(n log n) | O(1) | 否 |
| 插入排序 | O(n²) | O(n²) | O(1) | 是 |
