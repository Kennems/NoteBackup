# 蓝桥杯真题

## 一、竞赛概述

### 1.1 赛事介绍

蓝桥杯全国软件和信息技术专业人才大赛（简称"蓝桥杯"）是由工业和信息化部人才交流中心主办的全国性IT学科竞赛，每年一届，是国内规模最大的高校IT赛事之一。

- **参赛对象**：在校大学生（研究生、本科、高职高专）
- **竞赛分组**：
  - **研究生组**
  - **大学A组** — 985/211院校本科生（难度最高）
  - **大学B组** — 普通本科院校
  - **大学C组** — 高职高专院校
- **科目设置**：C/C++、Java、Python（三选一）

### 1.2 赛制说明

| 阶段 | 时间 | 形式 | 时长 |
|------|------|------|------|
| 省赛 | 每年4月 | 线上/线下闭卷上机 | 4小时 |
| 国赛（总决赛） | 每年5-6月 | 线下集中上机 | 4小时 |

- **题型**：10道编程题（无选择题/填空题），每题有多个测试点
- **评分方式**：黑盒测试，通过测试点数量计分
- **分值分布**：一般前2题约10分/题，中间5-6题约15分/题，最后2题约20-25分/题
- **省赛奖励**：一等奖10%、二等奖20%、三等奖30%（省一可晋级国赛）

### 1.3 难度层次

蓝桥杯A组题目难度跨度极大：
- **简单题**（约2-3题）：考察基础语法、简单模拟、基础数学
- **中等题**（约4-5题）：考察数据结构、搜索、DP、图论基础
- **难题**（约2-3题）：考察复杂DP、高级数据结构、思维题、数学构造

### A. 幸运数字

**题目大意**：如果一个十进制数字的各位数字之和等于其在二进制、八进制、十六进制下的各位数字之和，则称它为幸运数字。求第2023个幸运数字。

**思路分析**：
- 直接枚举正整数，对每个数分别计算十进制、二进制、八进制、十六进制的数位和
- 判断四个数位和是否相等
- 计数到2023时输出

**核心代码**：
```cpp
int sum(int x, int base) {
    int res = 0;
    while (x) { res += x % base; x /= base; }
    return res;
}
// 枚举：for (int i = 1; ; i++)
// 判断 sum(i,10)==sum(i,2)==sum(i,8)==sum(i,16)
```

### B. 有奖问答

**题目大意**：小蓝参加答题节目，初始分数为0，答对+10分，答错-10分（不低于0），回答10道题。当分数恰好达到100时获胜并立即结束。求所有可能的答题情况数。

**思路分析**：
- 状态定义：`dp[pos][score]` 表示回答到第 pos 题、当前分数为 score 的方案数
- 转移：答对 `dp[pos+1][score+10] += dp[pos][score]`，答错 `dp[pos+1][max(0, score-10)] += dp[pos][score]`
- 每当 score == 100 时累加答案
- 注意：一旦到达100分就结束，之后的状态不应继续转移

**复杂度**：`O(10 × 100)`，非常小，也可以用DFS记忆化搜索

### C. 平方差

**题目大意**：给定区间 `[L, R]`，统计有多少个数 `x` 可以表示为 `x = a² - b²` 的形式（a, b为非负整数）。

**思路分析**：
- 平方差公式：`a² - b² = (a+b)(a-b)`
- 令 `p = a+b`，`q = a-b`，则 `x = p × q`，且 `p` 和 `q` 同奇偶（因为 `a = (p+q)/2`, `b = (p-q)/2` 为整数）
- 结论：`x` 能表示为平方差 ↔ `x` 是奇数 或 `x` 是4的倍数
- 区间计数：`calc(R) - calc(L-1)`，其中 `calc(n) = (n+1)/2 + n/4`

**复杂度**：`O(1)` 数学结论直接计算

---

### D. 更小的数

**题目大意**：给定一个数字字符串，可以对其中的连续子串进行反转操作。求能使反转后的字符串字典序比原串小的子串个数。

**思路分析**：
- 枚举子串的左右端点 `[i, j]`，判断反转后是否更小
- 优化：`O(n²)` 就能过（n ≤ 5000），动规预处理
- 定义 `dp[i][j]` 表示子串 `[i, j]` 反转后是否更小：
  - 若 `s[i] > s[j]`，则反转后更小
  - 若 `s[i] < s[j]`，则反转后更大
  - 若 `s[i] == s[j]`，则取决于 `dp[i+1][j-1]`
- 从小区间向大区间递推

**复杂度**：`O(n²)`

### E. 颜色平衡树

**题目大意**：给定一棵有根树，每个节点有一种颜色。如果一个子树中每种颜色的出现次数相同，则称该子树是颜色平衡的。求颜色平衡的子树个数。

**思路分析**：
- 树上启发式合并（DSU on Tree / 莫队）
- 对每棵子树维护颜色出现频次、频次的种类数
- 当所有非零频次相等时 => 最大频次 × 颜色种类数 = 子树大小
- 用 `map<int,int>` 维护频次及其出现次数

**复杂度**：`O(n log n)`

### F. 买二赠一

**题目大意**：商店买两件商品，可以免去其中价格较低的那件。给定商品价格列表，求最少花费。

**思路分析**：
- 贪心：将价格从大到小排序，每买两件就免费得一件
- 具体做法：把价格降序排列，每3件一组（买2件，赠1件最低的）
- 但需注意：只能对未赠送的商品进行购买，因此使用队列或双指针维护
- 更简单的思路：排序后从大到小，每三个一组，前两个付钱，第三个免费

**复杂度**：`O(n log n)`

---

### G. 合并石子

**题目大意**：有一排石子堆，每次可以合并相邻且颜色相同的两堆，合并代价为两堆石子数之和，合并后颜色变化有特定规则。求最小代价和能否合并成一堆。

**思路分析**：
- 区间DP经典变种
- `dp[i][j][c]` 表示将区间 `[i, j]` 合并成一堆且颜色为 `c` 的最小代价
- 转移时枚举分割点 `k`，若 `dp[i][k][c]` 和 `dp[k+1][j][c]` 都有值，则可合并
- 类似"石子合并"的升级版，加入颜色维度

**复杂度**：`O(n³ × C)`，C为颜色数

---

### H. 翻转硬币

**题目大意**：有 n 枚硬币排成一排，初始全部反面朝上。每次可以翻转一段连续区间。问最少操作次数使所有硬币正面朝上，或输出 -1 表示不可能。

**思路分析**：
- 这是一个经典的差分 + 数论问题
- 用差分数组 `diff[i]` 表示相邻位置翻转次数的差
- 根据操作性质，转化为关于每个位置是否操作的线性方程
- n 较大时需要使用莫比乌斯反演或数论分块优化

**复杂度**：`O(n log n)` 或 `O(n)` 根据实现

---

### I. 严格递增序列

**题目大意**：给定一个数组，每次操作可以将任意一个元素增加1。求最少操作次数使数组变为严格递增。

**思路分析**：
- 贪心：从左到右遍历，若当前数 ≤ 前一个数，则将其增加到前一个数+1
- 这是标准解法，但需注意题目是否有额外约束
- 若有非严格递增则更简单：`max(prev+1, cur)` 即可
- 更复杂的变种是带区间修改，但基础版贪心即可

**复杂度**：`O(n)`

---

### J. 奇怪的数

**题目大意**：求长度为 n 的"奇怪数"的个数，奇怪数定义为：十进制下各位数字满足某种约束（如相邻位之差满足特定条件、不含某些数字等），结果对 MOD 取模。

**思路分析**：
- 数位DP + 状态压缩
- 当 n 较大（如 ≤ 10⁵）时，需要用矩阵快速幂优化
- 状态：`dp[pos][state]` 表示填到第 pos 位、当前状态下的方案数
- 转移矩阵构建：若状态 u 可以转移到 v，则矩阵 A[u][v] = 1
- 答案：初始向量 × Aⁿ

**复杂度**：`O(S³ log n)`，S为压缩后的状态数

## 四、竞赛技巧与策略

### 4.1 时间分配策略（4小时）

| 时间段 | 目标 | 策略 |
|--------|------|------|
| 0-30min | 通读所有题目 | 快速审题，标记难度，不要深入思考 |
| 30-90min | 拿下送分题 | 先A后B再C，确保前3题拿满 |
| 90-150min | 攻克中等题 | 选自己最擅长的2-3题突破 |
| 150-210min | 挑战难题 | 争取部分分，写暴力和特殊数据 |
| 210-240min | 检查复盘 | 检查边界、数据类型、文件名、输入输出格式 |

### 4.2 得分策略

- **前3题务必AC**：这是省一的基础保障
- **暴力分不放过**：即使不会正解，写暴力也能拿30%-50%的测试点分
- **特判拿分**：n=1、边界情况等特殊情况单独处理
- **适当放弃**：最后1-2题如果20分钟没有思路，不如回头检查前面的题
- **文件名规范**：每题输出文件名为题目英文名，注意大小写

### 4.3 编程注意事项

- **数据类型**：注意 long long（64位），防止溢出
- **取模运算**：结果涉及大数时记得取模，注意负数的取模处理
- **数组大小**：开全局数组，栈上开大数组可能导致运行时错误
- **输入输出加速**：
  ```cpp
  ios::sync_with_stdio(false);
  cin.tie(nullptr);
  ```
- **STL使用**：熟悉 map、set、priority_queue、vector 等，注意复杂度

## 七、常见坑点总结

1. **忘记开 long long**：大数运算结果溢出，扣分最冤
2. **数组越界**：注意下标从0还是1开始，注意开 `n+5` 而非 `n`
3. **多组测试数据未重置全局变量**：建议使用局部变量或用 `memset` 重置
4. **输入输出格式问题**：严格按照题目要求输出空格/换行
5. **文件名拼写错误**：交卷前务必检查文件名和题目是否一致
6. **取模坑点**：负数取模在 C++ 中可能得到负数，需要 `(x % MOD + MOD) % MOD`
7. **浮点数精度**：涉及实数比较时使用 `1e-6` 容差
8. **递归爆栈**：深度太大时改用迭代或者开栈空间

---

> **最后**：蓝桥杯的核心考察的是 **算法能力 + 编码速度 + 调试能力**。多刷真题、多总结模板、多限时训练，是冲击国奖的最佳路径。
