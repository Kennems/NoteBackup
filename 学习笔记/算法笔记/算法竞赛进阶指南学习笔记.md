# 算法竞赛进阶指南学习笔记

知识点整理 算法题全解

## 0x00 基本算法

### 位运算

常用技巧：`x & -x` 取 lowbit；`x & (x - 1)` 消去最低位 1；`x >> k & 1` 取第 k 位；`x ^ 1` 翻转最低位。枚举子集：`for (int sub = S; sub; sub = (sub - 1) & S)`。

```cpp
int lowbit(int x) { return x & -x; }
int popcount(int x) { int c = 0; while (x) x &= x - 1, c++; return c; }
```

### 递推与递归

```cpp
int qpow(int a, int b, int mod) {
    int res = 1;
    while (b) { if (b & 1) res = 1LL * res * a % mod; a = 1LL * a * a % mod; b >>= 1; }
    return res;
}
```

### 枚举

指数枚举（子集）、组合枚举（DFS 选 k 个）、排列枚举（`next_permutation`）。

```cpp
for (int i = 0; i < (1 << n); i++)          // 子集枚举
    for (int j = 0; j < n; j++)
        if (i >> j & 1) { /* 选 j */ }
```

### 前缀和与差分

一维前缀和：`s[i] = s[i-1] + a[i]`，区间和 `sum[l,r] = s[r] - s[l-1]`。

二维前缀和：`s[i][j] = s[i-1][j] + s[i][j-1] - s[i-1][j-1] + a[i][j]`。

一维差分：`d[l] += c, d[r+1] -= c`；二维类似，四个角操作后求前缀和还原。

### 二分

整数二分注意边界处理：

```cpp
// 找第一个 >= x 的位置
while (l < r) { int mid = l + (r - l) / 2; if (a[mid] >= x) r = mid; else l = mid + 1; }
// 找最后一个 <= x 的位置
while (l < r) { int mid = l + (r - l + 1) / 2; if (a[mid] <= x) l = mid; else r = mid - 1; }
```

实数二分：固定迭代次数（如 100 次）避免精度问题。

### 排序

```cpp
// 离散化
sort(v.begin(), v.end());
v.erase(unique(v.begin(), v.end()), v.end());
for (int i = 0; i < n; i++) a[i] = lower_bound(v.begin(), v.end(), a[i]) - v.begin() + 1;

// 归并排序求逆序对
void merge_sort(int l, int r) {
    if (l >= r) return;
    int mid = l + r >> 1, i = l, j = mid + 1, k = l;
    merge_sort(l, mid); merge_sort(mid + 1, r);
    while (i <= mid && j <= r) {
        if (a[i] <= a[j]) tmp[k++] = a[i++];
        else tmp[k++] = a[j++], ans += mid - i + 1;
    }
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= r) tmp[k++] = a[j++];
    for (i = l; i <= r; i++) a[i] = tmp[i];
}
```

### 贪心

经典问题：区间选点（按右端点排序）、区间不相交（能选则选）、区间覆盖（左端点排序，每次选能覆盖且右端点最远的）。证明方法：邻项交换、范围缩放。

```cpp
sort(r, r + n, [](Range a, Range b) { return a.r < b.r; });
int ans = 0, last = -2e9;
for (int i = 0; i < n; i++) if (r[i].l > last) ans++, last = r[i].r;
```

## 0x10 基本数据结构

### 栈与队列

```cpp
// 单调栈：找左侧第一个小于当前值的元素
stack<int> st;
for (int i = 0; i < n; i++) {
    while (st.size() && a[st.top()] >= a[i]) st.pop();
    l[i] = st.empty() ? -1 : st.top(); st.push(i);
}

// 单调队列：滑动窗口最值
deque<int> q;
for (int i = 0; i < n; i++) {
    while (q.size() && q.front() < i - k + 1) q.pop_front();
    while (q.size() && a[q.back()] <= a[i]) q.pop_back();
    q.push_back(i);
    if (i >= k - 1) ans[i - k + 1] = a[q.front()];
}
```

### 链表

数组模拟快于指针：`int l[N], r[N], e[N], idx;`

邻接表存图：`int h[N], e[M], ne[M], idx;`，`add(a,b)` 头插法，遍历 `for (int i = h[u]; ~i; i = ne[i])`。

### 哈希与字符串

开放寻址法：`const int N = 200003, null = 0x3f3f3f3f;` `find(x)` 线性探测。

字符串哈希（自然溢出）：

```cpp
typedef unsigned long long ULL;
const int P = 131;
ULL h[N], p[N];
ULL get(int l, int r) { return h[r] - h[l-1] * p[r-l+1]; }
```

### KMP

```cpp
void get_next(char s[]) {
    for (int i = 2, j = 0; s[i]; i++) {
        while (j && s[i] != s[j+1]) j = ne[j];
        if (s[i] == s[j+1]) j++;
        ne[i] = j;
    }
}
```

`ne[i]` 表示前缀 `s[1..i]` 的最长 border 长度。最小循环节：`len - ne[len]`。

### Trie

```cpp
int son[N][26], cnt[N], idx;
void insert(char s[]) {
    int p = 0;
    for (int i = 0; s[i]; i++) {
        int u = s[i] - 'a';
        if (!son[p][u]) son[p][u] = ++idx;
        p = son[p][u];
    }
    cnt[p]++;
}
```

01-Trie 可求最大异或对：贪心走相反分支。

### 并查集

```cpp
int find(int x) {
    if (p[x] != x) { int r = find(p[x]); d[x] += d[p[x]]; p[x] = r; }
    return p[x];
}
void unite(int a, int b) {
    a = find(a), b = find(b);
    if (a == b) return;
    if (siz[a] < siz[b]) swap(a, b);
    p[b] = a, siz[a] += siz[b];
}
```

带权并查集维护到根距离，可扩展域并查集维护多个关系。

## 0x20 搜索

### DFS 与 BFS

```cpp
// DFS 全排列
int path[N]; bool vis[N];
void dfs(int u, int n) {
    if (u == n) { /* 输出 */ return; }
    for (int i = 1; i <= n; i++) if (!vis[i]) {
        vis[i] = true; path[u] = i; dfs(u + 1, n); vis[i] = false;
    }
}

// BFS 最短路（边权为 1）
queue<int> q; memset(dist, -1, sizeof dist); dist[s] = 0; q.push(s);
while (q.size()) {
    int t = q.front(); q.pop();
    for (int v : adj[t]) if (dist[v] == -1) dist[v] = dist[t] + 1, q.push(v);
}
```

双端队列 BFS（01 边权）：边权 0 push_front，边权 1 push_back。

### 剪枝技巧

1. **优化搜索顺序**：优先搜索分支少的节点
2. **可行性剪枝**：当前状态不可能达到目标
3. **最优性剪枝**：当前答案 >= 已知最优解
4. **记忆化搜索**：记录已算过的状态

```cpp
// 小猫爬山：排序 + 最优性剪枝
int ans = N;
sort(cat, cat + n, greater<int>());
void dfs(int now, int cnt) {
    if (cnt >= ans) return;
    if (now == n) { ans = cnt; return; }
    for (int i = 0; i < cnt; i++) if (cab[i] + cat[now] <= w) {
        cab[i] += cat[now]; dfs(now + 1, cnt); cab[i] -= cat[now];
    }
    cab[cnt] = cat[now]; dfs(now + 1, cnt + 1); cab[cnt] = 0;
}
```

### IDA* 与 A*

**A\***：`f(n) = g(n) + h(n)`，h(n) 需可采纳（<= 实际代价）。求第 K 短路时启发函数为到终点的最短路。

**IDA\***：迭代加深 + 估值函数剪枝。`if (now + h() > depth) return;`。

```cpp
// IDA* 框架
int depth = 0;
while (!dfs(0, -1)) depth++;
cout << depth << '\n';
```

## 0x70 综合技巧与实践

### 常用技巧

- **二进制状态压缩**：int 表示集合，位运算快速操作
- **倍增**：ST 表、LCA、快速幂，O(log n)
- **双指针**：单调性优化 O(n^2) -> O(n)
- **差分约束**：最短路模型转化不等式
- **分治**：CDQ 分治、点分治、整体二分

```cpp
// 双指针：最长不重复子序列
for (int i = 0, j = 0; i < n; i++) {
    cnt[a[i]]++;
    while (cnt[a[i]] > 1) cnt[a[j++]]--;
    ans = max(ans, i - j + 1);
}

// ST 表 RMQ
for (int j = 1; j < LOG; j++)
    for (int i = 1; i + (1 << j) - 1 <= n; i++)
        st[j][i] = max(st[j-1][i], st[j-1][i+(1<<(j-1))]);
int query(int l, int r) {
    int k = __lg(r - l + 1);
    return max(st[k][l], st[k][r-(1<<k)+1]);
}
```

### 常见错误

- 数组大小：边数 M 开 2x，注意 N、M 定义
- 整数溢出：`1LL * a * b`
- 多组数据清空：重置 idx、h[] 数组
- 二分边界：mid 取整方向
- 负数的模：`(x % MOD + MOD) % MOD`
- 快读和取消同步：`ios::sync_with_stdio(false); cin.tie(nullptr);`
